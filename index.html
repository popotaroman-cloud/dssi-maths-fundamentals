01สมการและผลเฉลย

ผลเฉลยแปลกปลอม · สมการเชิงเส้น/กำลังสอง · สมการเศษส่วน/กรณฑ์ · อสมการ
Lecture note แบบฝึกหัด
สไลด์ 4 ชุด
1. ผลเฉลยคืออะไร — สมการสมมูลและผลเฉลยแปลกปลอม 2. สมการเชิงเส้นและสมการกำลังสอง 3. สมการเศษส่วนและสมการกรณฑ์ 4. อสมการและตารางเครื่องหมาย

02ระบบสมการ + เอกซ์โพเนนเชียล–ลอการิทึม

ระบบสมการเชิงเส้น (row reduction) · overdetermined · exp/log · sigmoid/logit
Lecture note แบบฝึกหัด
สไลด์ 4 ชุด
1. ระบบสมการเชิงเส้น — อ่านผลลัพธ์ให้เป็น 2. ระบบ Overdetermined 3. เอกซ์โพเนนเชียลและลอการิทึม 4. log ใน DS/CS

03อนุพันธ์

นิยาม difference quotient · กฎการหาอนุพันธ์ · กฎลูกโซ่ · ความเพิ่ม-ลด/ความเว้า/จุดวิกฤต
Lecture note แบบฝึกหัด
สไลด์ 3 ชุด
1. จากอัตราการเปลี่ยนแปลงเฉลี่ยถึงอนุพันธ์ 2. กฎการหาอนุพันธ์ 3. การตีความ — เพิ่ม-ลด ความเว้า จุดวิกฤต

04อนุพันธ์ย่อยและเกรเดียนต์

ฟังก์ชันหลายตัวแปร/contour · อนุพันธ์ย่อย · เกรเดียนต์ · กฎลูกโซ่หลายตัวแปร
Lecture note แบบฝึกหัด
สไลด์ 4 ชุด
1. ฟังก์ชันหลายตัวแปรและ contour 2. อนุพันธ์ย่อย 3. เกรเดียนต์ ∇f 4. กฎลูกโซ่หลายตัวแปร

05การหาค่าเหมาะที่สุด + Capstone

Optimization 1-var/2-var · Capstone: สร้างสูตร Linear Regression ด้วยมือ · Gradient Descent (bridge)
Lecture note แบบฝึกหัด
สไลด์ 4 ชุด
1. การหาค่าเหมาะที่สุดของฟังก์ชันหนึ่งตัวแปร 2. การหาค่าเหมาะที่สุดของฟังก์ชันสองตัวแปร 3. Capstone — สร้างสูตร Linear Regression ด้วยมือ 4. Gradient Descent — ประตูเชื่อมไปคอร์ส 15 สัปดาห์
