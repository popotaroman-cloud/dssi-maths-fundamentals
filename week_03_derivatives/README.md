# สัปดาห์ 3 — อนุพันธ์

## เป้าหมาย

หาอนุพันธ์ได้คล่อง โดยเฉพาะ **กฎลูกโซ่** และอ่านความหมายของ $f'$ กับ $f''$ ได้ — สัปดาห์นี้มีงานเดียวคือทำให้กฎลูกโซ่แม่น จึงตัดหัวข้ออื่นออกอย่างไม่เสียดายเพื่อเอาเวลาไปฝึก

จบสัปดาห์นี้ควรทำได้:
- หา $f'(a)$ จากนิยาม difference quotient โดยตัด $h$ ก่อนแทนค่า
- เขียนสมการเส้นสัมผัส และระบุจุดที่อนุพันธ์ไม่มีอยู่
- ใช้กฎยกกำลัง ผลบวก ผลคูณ ผลหาร และ **กฎลูกโซ่** ได้คล่อง ทั้งซ้อนสองชั้นและสามชั้น
- หาอนุพันธ์ของ $e^{g(x)}$ และ $\ln g(x)$
- อ่านเครื่องหมายของ $f'$ และ $f''$ เป็นรูปร่างกราฟ และหาจุดวิกฤตได้
