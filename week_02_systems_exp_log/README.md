# สัปดาห์ 2 — ระบบสมการ + เอกซ์โพเนนเชียล–ลอการิทึม

## เป้าหมาย

อ่านผลเฉลยทั่วไปของระบบสมการเชิงเส้นได้ และแก้สมการเลขชี้กำลัง–ลอการิทึมได้คล่องพร้อมเช็คโดเมนทุกครั้ง

จบสัปดาห์นี้ควรทำได้:
- อ่านสามกรณีของระบบสมการ (ผลเฉลยเดียว / ไม่มี / มากมาย) จาก echelon form ได้ทันที
- นับตัวแปรอิสระและเขียนผลเฉลยทั่วไปแบบพารามิเตอร์ได้ถูกรูป
- อธิบายว่าระบบ overdetermined คืออะไร และทำไมมักไม่มีผลเฉลยพอดี
- แก้สมการเลขชี้กำลังและลอการิทึมได้แม่น พร้อมขั้นตอนเช็คโดเมนสี่ขั้น
- อธิบายว่าทำไม binary search เป็น $O(\log n)$ และกลับด้าน sigmoid เป็น logit ได้

## การปิดวงและตั้งค้าง

**ปิดวงจากสัปดาห์ 1:** กฎ $\log a + \log b = \log(ab)$ ที่ทำให้เซตคำตอบบวมขึ้น — สัปดาห์นี้กลับมาเต็มรูปในหัวข้อ 3 พร้อมขั้นตอนทำงานที่ใช้ได้ทุกครั้ง (ดูตัวอย่างที่ 3.4 ใน note)

**ตั้งค้างไว้ให้สัปดาห์ 5:** ระบบ overdetermined ที่ไม่มีผลเฉลยพอดี — คำถาม "ถ้าไม่มีผลเฉลยพอดี จะเลือกคำตอบที่ดีที่สุดอย่างไร" จะได้คำตอบเต็มรูปใน Capstone สัปดาห์ 5 (สร้างสูตร linear regression ด้วยมือ)
