# สัปดาห์ 1 — สมการและผลเฉลย

## เป้าหมาย

แก้สมการได้หลายชนิด และ **ตรวจคำตอบเป็น** — รู้ว่าคำตอบที่ได้มาคำตอบไหนใช้ได้จริง

จบสัปดาห์นี้ควรทำได้:
- บอกเซตคำตอบของสมการได้ และเข้าใจว่าการแก้สมการคือการหาเซต ไม่ใช่หาตัวเลขหนึ่งตัว
- ระบุขั้นตอนที่เป็น $\Longrightarrow$ (เซตคำตอบบวม) กับ $\Longleftarrow$ (เซตคำตอบหด) ได้
- แก้สมการเชิงเส้น กำลังสอง เศษส่วน และกรณฑ์ ได้พร้อมตรวจคำตอบ
- ใช้ discriminant บอกธรรมชาติของรากได้โดยไม่ต้องแก้สมการ
- แก้อสมการด้วยตารางเครื่องหมาย

**สัปดาห์แรกของคอร์ส — ยังไม่มีอะไรให้ปิดวง**
