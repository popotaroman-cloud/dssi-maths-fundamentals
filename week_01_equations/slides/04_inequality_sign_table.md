## Slide 2 — ภาพรวมช่วงนี้

**Key Message**: เมื่อจบช่วงนี้ ผู้เรียนควรไม่คูณอสมการด้วยนิพจน์ที่มีตัวแปรอีกต่อไป เพราะจะเข้าใจได้ว่าการดำเนินการดังกล่าวผิดพลาดตรงจุดใด

**จะเรียน:**

- **ตารางเครื่องหมาย** สามขั้น
- กับดักการหารด้วย $x$ และกับดักการคูณไขว้
- จุดวิกฤตจากตัวเศษ กับ จุดวิกฤตจากตัวส่วน ต่างกันตอนเขียนคำตอบ

## Slide 3 — อสมการต่างจากสมการที่จุดเดียว

**Key Message**: คูณหรือหารด้วยจำนวนลบทำให้ทิศกลับ — และนิพจน์ที่มีตัวแปรไม่รู้ว่าเป็นบวกหรือลบ จึงห้ามใช้คูณหาร

$$
a < b \quad\text{และ}\quad c < 0 \quad\Longrightarrow\quad ac > bc
$$

ผลที่ตามมาซึ่งเป็นกฎเหล็กของช่วงนี้

- **ห้ามคูณหรือหารอสมการด้วยนิพจน์ที่มีตัวแปร** ไม่ว่ากรณีใด เพราะไม่รู้ว่าต้องกลับทิศหรือไม่
- **ห้ามคูณไขว้** ในอสมการเศษส่วน — เป็นกรณีเฉพาะของข้อบน
- ทางเดียวที่ปลอดภัยคือ **ย้ายมาข้างเดียว** แล้วดูเครื่องหมายของนิพจน์ทั้งก้อน

---

## Slide 4 — ตัวอย่างเชิงเส้น: ทิศกลับเมื่อไร

**Key Message**: เขียนคำว่าทิศกลับกำกับบรรทัดนั้นทุกครั้ง จะไม่พลาดเพราะทำเร็ว

$$
\begin{aligned}
3x - 5 &< 7 && \\
3x &< 12 && \\
x &< 4 && \text{หารด้วย } 3 \;\text{ (บวก — ทิศไม่กลับ)} \;\Rightarrow\; (-\infty, 4)
\end{aligned}
$$

$$
\begin{aligned}
-2x + 1 &\ge 7 && \\
-2x &\ge 6 && \\
x &\le -3 && \text{หารด้วย } -2 \;\Rightarrow\; \textbf{ทิศกลับ} \;\Rightarrow\; (-\infty, -3]
\end{aligned}
$$

**ตรวจคำตอบ:** ลองค่าในช่วงและนอกช่วงเสมอ — $x=0$ ในข้อสอง ได้ $1 \ge 7$ เท็จ ✓ สอดคล้อง

## Slide 5 — ตารางเครื่องหมาย: สามขั้น

**Key Message**: ตารางเครื่องหมายใช้ได้กับทุกอสมการที่ไม่เป็นเชิงเส้น และเป็นวิธีเดียวที่ปลอดภัยเสมอ

```
ขั้น 1   จัดให้อยู่รูป (นิพจน์) > 0  หรือ  >= 0
         ย้ายทุกอย่างมาข้างเดียว รวมเป็นเศษส่วนเดียว   ห้ามคูณไขว้

ขั้น 2   หาค่าวิกฤต
         จากตัวเศษ = 0        ->  รวมเข้าคำตอบได้ ถ้ามีเครื่องหมายเท่ากับ
         จากตัวส่วน = 0        ->  รวมเข้าคำตอบไม่ได้เลย

ขั้น 3   ตรวจเครื่องหมายของแต่ละตัวประกอบในแต่ละช่วง แล้วคูณเครื่องหมาย
```

ความต่างของค่าวิกฤตสองชนิดในขั้น 2 คือจุดที่นักศึกษาเสียคะแนนมากที่สุดในเรื่องนี้

## Slide 6 — ตัวอย่างกำลังสอง: กับดักการหารด้วย $x$

**Key Message**: การหารด้วย $x$ ทำให้ช่วงที่ $x$ เป็นลบหลุดออกจากการพิจารณาไปทั้งหมด

**โจทย์:** แก้ $x^2 \le 4x$

$$
x^2 - 4x \le 0 \;\Longleftrightarrow\; x(x-4) \le 0 \qquad \text{ค่าวิกฤต } 0 \text{ และ } 4
$$

```
ช่วง            x < 0      0 < x < 4      x > 4
x                 -            +            +
(x - 4)           -            -            +
ผลคูณ             +            -            +
```

ค่าวิกฤตทั้งสองมาจากตัวเศษ จึงรวมเข้าไปได้ → **ตอบ** $[0, 4]$

**ถ้าหารด้วย $x$** จะได้ $x \le 4$ ซึ่งผิด เพราะรวม $x$ ที่เป็นลบทั้งหมดเข้ามาด้วย

---

## Slide 7 — ตัวอย่างเศษส่วน: ห้ามคูณไขว้

**Key Message**: ค่าวิกฤตที่มาจากตัวส่วนรวมเข้าคำตอบไม่ได้ ต่างจากค่าที่มาจากตัวเศษ

**โจทย์:** แก้ $\dfrac{x+3}{x-1} \ge 2$ · โดเมน $x \ne 1$

$$
\frac{x+3}{x-1} - 2 \ge 0 \;\Longleftrightarrow\; \frac{(x+3) - 2(x-1)}{x-1} \ge 0 \;\Longleftrightarrow\; \frac{5-x}{x-1} \ge 0
$$

```
ช่วง            x < 1      1 < x < 5      x > 5
(5 - x)           +            +            -
(x - 1)           -            +            +
ผลหาร             -            +            -
```

$x=5$ มาจากตัวเศษ → รวมได้ · $x=1$ มาจากตัวส่วน → รวมไม่ได้ → **ตอบ** $(1, 5]$

[FIGURE | A | w01_f04_sign_table_rational | ตารางเครื่องหมายของนิพจน์ (5-x)/(x-1) วาดเป็นเส้นจำนวนแนวนอนมีจุดวิกฤตสองจุดคือ 1 กับ 5 จุดที่ 1 เป็นวงกลมโปร่งกำกับว่าไม่นิยาม จุดที่ 5 เป็นวงกลมทึบ ใต้เส้นจำนวนมีสามแถวคือเครื่องหมายของตัวเศษ ตัวส่วน และผลหาร ช่วงคำตอบระบายแถบทึบไว้ระหว่าง 1 ถึง 5 ขาวดำ เส้นน้อย]

## Slide 8 — ใช้ทำอะไรใน DS/CS

**Key Message**: เหตุผลจริงที่คอร์สนี้เก็บอสมการไว้ทั้งที่ตัดหัวข้ออื่นออกมาก คือตารางเครื่องหมายจำเป็นในสัปดาห์ 5

**อสมการเป็นภาษาของการรับประกันเชิงปริมาณ** ทุกครั้งที่ระบุว่าอัลกอริทึมใช้เวลาไม่เกินเท่าใด หรือค่าประมาณคลาดเคลื่อนไม่เกินเท่าใด สิ่งที่เขียนอยู่คืออสมการ · รูป $\lvert x - \hat x \rvert \le \varepsilon$ คือหัวใจของทั้งการวิเคราะห์ความคลาดเคลื่อนเชิงตัวเลขและช่วงความเชื่อมั่น

**แต่เหตุผลหลักคือตารางเครื่องหมาย** — สัปดาห์ 5 การหาว่าฟังก์ชันเพิ่มหรือลดที่ช่วงไหน ทำโดยหาค่าวิกฤตของ $f'$ แล้วทำตารางเครื่องหมายของ $f'$

$$
\text{ตารางเครื่องหมายของ } (x-2)(x-3) \quad\longleftrightarrow\quad \text{ตารางเครื่องหมายของ } f'(x)
$$

เป็นกระบวนการเดียวกันโดยตรง ต่างกันเพียงนิพจน์ที่นำมาใส่ในตาราง **ผู้ที่ยังไม่ชำนาญเรื่องตารางเครื่องหมายในวันนี้ จะไม่สามารถทำ first derivative test ได้ในสัปดาห์ 5**

## Slide 9 — สรุปและสิ่งที่ต้องทำ

**Key Message**: ห้ามคูณหรือหารด้วยนิพจน์ที่มีตัวแปร และแยกให้ชัดว่าจุดวิกฤตมาจากตัวเศษหรือตัวส่วน

**จบสัปดาห์ 1 ควรทำได้:**
- แก้อสมการเชิงเส้น กำลังสอง และเศษส่วน ด้วยตารางเครื่องหมาย
- เขียนคำตอบเป็นช่วง และรู้ว่าปลายช่วงไหนปิดไหนเปิด
- อธิบายได้ว่าทำไมห้ามคูณไขว้ในอสมการ

**สามข้อของสัปดาห์นี้:**
1. ตรวจคำตอบกับสมการตั้งต้น ไม่ใช่กับบรรทัดสุดท้ายของตัวเอง
2. ห้ามหารด้วยนิพจน์ที่มีตัวแปร ทั้งในสมการและอสมการ
3. เขียนโดเมนเป็นบรรทัดแรกทุกครั้งที่มีตัวส่วนหรือกรณฑ์
