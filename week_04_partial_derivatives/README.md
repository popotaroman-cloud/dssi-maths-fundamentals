## เป้าหมายของสัปดาห์นี้

**เป้าหมายหลัก:** หาอนุพันธ์ย่อยได้คล่อง และรู้ว่าเกรเดียนต์ชี้ทิศอะไร

จบสัปดาห์นี้ผู้เรียนควรทำสิ่งเหล่านี้ได้:

1. อ่านและวาด **contour / level curve** ของ $f(x,y)$ ด้วยดินสอ และบอกได้ว่าเส้นที่ชิดกันหมายถึงอะไร
2. หา $f_x$, $f_y$ ได้โดย **เขียนออกมาให้เห็นว่าตรึงตัวแปรไหนไว้** และหาค่าที่จุดที่กำหนดได้
3. หาอนุพันธ์ย่อยอันดับสองและแบบผสม $f_{xx}, f_{yy}, f_{xy}, f_{yx}$ ได้ และใช้ข้อเท็จจริง $f_{xy} = f_{yx}$ เป็นเครื่องตรวจงานตัวเอง
4. เขียน $\nabla f$ ที่จุดหนึ่งเป็นคู่อันดับ และอธิบายความหมายเชิงเรขาคณิตได้สองข้อ: **ทิศที่ฟังก์ชันเพิ่มชันที่สุด** และ **ตั้งฉากกับ level curve**
5. ใช้ **กฎลูกโซ่หลายตัวแปร** กับโจทย์ซ้อน 3 ชั้น และตรวจคำตอบด้วยการแทนค่าย้อนกลับ
6. หา $\nabla L(w,b)$ ของ $L(w,b) = \sum (y_i - wx_i - b)^2$ ได้ครบทั้งสองช่อง

**สิ่งที่ถือว่ารู้มาแล้ว:** อนุพันธ์หนึ่งตัวแปรและกฎลูกโซ่ (สัปดาห์ 3) · การแก้ระบบสมการเชิงเส้น (สัปดาห์ 2) · เวกเตอร์และคู่อันดับ

## หัวข้อที่ **ตัดออก** จากสัปดาห์นี้ (อย่าเผลอเพิ่มกลับ)

อนุพันธ์ตามทิศทาง · เมทริกซ์อนุพันธ์อันดับสอง · เมทริกซ์อนุพันธ์ย่อยอันดับหนึ่งของฟังก์ชันหลายเอาต์พุต · การส่งค่าย้อนกลับในโมเดลแบบชั้น · vanishing gradient

> เหตุผล: ทั้งหมดเป็นเนื้อหาของคอร์ส **Maths for Data Science (15 สัปดาห์)** ภาคถัดไป ซึ่งมีเวลาสอนมากกว่าและสอนได้ดีกว่า · สัปดาห์นี้มีงานเดียวคือ **ทำให้อนุพันธ์ย่อยแม่นและอ่านเกรเดียนต์เป็น**

## หมายเหตุสำหรับผู้สอน

- **ช่วง 70 นาทีคือแกนของสัปดาห์** ถ้าเวลาไม่พอ ให้ตัดจากช่วง 40 นาทีแรก (contour) ไม่ใช่จากช่วง 70 นาที
- $f_{xy} = f_{yx}$ ให้ **บอกเป็นข้อเท็จจริง** ไม่ต้องพิสูจน์ ไม่ต้องเรียกชื่อทฤษฎีบท — ใช้มันเป็นเครื่องตรวจงานตัวเองแทน
- ทุกครั้งที่หาอนุพันธ์ย่อยบนกระดาน **ให้เขียนบรรทัด "ตรึง $y$ ไว้ ถือ $y$ เป็นค่าคงตัว" ก่อนลงมือ** นี่คือนิสัยที่กันความผิดพลาดได้มากที่สุดในสัปดาห์นี้
- ตอนจบช่วง 70 นาที ให้หยุดที่ $\nabla L(w,b)$ อย่างตั้งใจ และพูดออกมาดัง ๆ ว่า **"สัปดาห์หน้าเราจะให้มันเท่ากับศูนย์แล้วแก้"** ความค้างใจตรงนี้คือเชื้อเพลิงของ Capstone
