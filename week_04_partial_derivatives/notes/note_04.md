## สัปดาห์นี้จะได้อะไร

**เป้าหมาย:** หาอนุพันธ์ย่อยได้คล่องแบบไม่ต้องคิด และรู้ว่าเกรเดียนต์ชี้ไปทางไหนและตั้งฉากกับอะไร

จบสัปดาห์นี้คุณควรทำสิ่งเหล่านี้ได้:

- วาด contour ของ $f(x,y)$ ด้วยดินสอ และอ่านได้ว่าเส้นที่ชิดกันบอกอะไร
- หา $f_x(a,b)$ และ $f_y(a,b)$ โดยเขียนให้เห็นชัดว่า **ตรึงตัวแปรไหนไว้**
- หา $f_{xx}, f_{yy}, f_{xy}, f_{yx}$ และใช้ $f_{xy} = f_{yx}$ ตรวจงานตัวเอง
- เขียน $\nabla f(a,b)$ เป็นคู่อันดับ และอธิบายความหมายเชิงเรขาคณิตได้
- ใช้กฎลูกโซ่หลายตัวแปรกับโจทย์ซ้อนสามชั้น พร้อมตรวจคำตอบด้วยการแทนค่าย้อนกลับ

**สิ่งที่ถือว่ารู้มาแล้ว:** อนุพันธ์หนึ่งตัวแปรและ**กฎลูกโซ่**จากสัปดาห์ 3 · การแก้ระบบสมการเชิงเส้นจากสัปดาห์ 2 · คู่อันดับและเวกเตอร์ในระนาบ

**เรื่องที่สัปดาห์นี้ปิดวงให้:** กฎลูกโซ่ของสัปดาห์ 3 ที่ตอนนั้นทำได้เฉพาะโซ่เส้นเดียว $t \to u \to z$ สัปดาห์นี้จะขยายเป็นโซ่ที่แตกกิ่ง $t \to (x, y) \to z$ ได้จริง

**เรื่องที่สัปดาห์นี้ตั้งค้างไว้:** เราจะหา $\nabla L(w,b)$ ของ loss function $L(w,b) = \sum (y_i - wx_i - b)^2$ **ให้ครบทั้งสองช่อง แล้วหยุดตรงนั้น** — สัปดาห์หน้าเราจะให้มันเท่ากับศูนย์แล้วแก้ระบบสมการที่ได้ออกมา นั่นคือ Capstone ของคอร์สนี้ ในสัปดาห์นี้เราจะ **ไม่แก้** และ **ไม่เฉลยสูตร**

# 1. ฟังก์ชันหลายตัวแปรและ contour

*(ตรงกับแถวที่ 1 ในตาราง 180 นาที — Concept 40 นาที)*

## 1.1 หลักการ

ตลอดสัปดาห์ 3 เราทำงานกับฟังก์ชันที่รับตัวเลขหนึ่งตัวแล้วคืนตัวเลขหนึ่งตัว เขียนว่า $f(x)$ กราฟของมันเป็นเส้นโค้งในระนาบ และ "ความชัน" ที่จุดหนึ่งเป็นตัวเลขหนึ่งตัว เพราะยืนอยู่บนเส้นโค้งแล้วเดินได้แค่สองทาง คือหน้าและหลัง

ปัญหาจริงใน Data Science ไม่มีหน้าตาแบบนั้น เวลาเราฟิตเส้นตรง $y = wx + b$ เข้ากับข้อมูล เราไม่ได้ปรับตัวเลขตัวเดียว เราปรับ **สองตัว** พร้อมกัน คือความชัน $w$ และจุดตัดแกน $b$ ความเลวของเส้นตรงหนึ่งเส้นจึงเป็นฟังก์ชันของสองตัวแปร ไม่ใช่หนึ่ง เขียนว่า $L(w, b)$ เมื่อโมเดลมีพารามิเตอร์ 20 ตัว ฟังก์ชันความเลวก็มี 20 ตัวแปร กรณีสองตัวแปรที่เราจะเรียนสัปดาห์นี้ไม่ใช่กรณีของเล่น มันเป็นกรณีเล็กที่สุดที่ยังมีปัญหาสำคัญทุกอย่างของกรณีใหญ่อยู่ครบ

**ฟังก์ชันสองตัวแปร** $f(x,y)$ คือกฎที่รับคู่อันดับ $(x,y)$ เข้าไปแล้วคืนจำนวนจริงออกมาหนึ่งตัว โดเมนของมันเป็นเซตของจุดในระนาบ ไม่ใช่ช่วงบนเส้นจำนวน

$$
f : D \subseteq \mathbb{R}^2 \longrightarrow \mathbb{R}, \qquad (x, y) \longmapsto f(x,y)
$$

กราฟของ $f$ ต้องใช้สามมิติ เพราะต้องมีแกนสำหรับ $x$ แกนสำหรับ $y$ และแกนสำหรับค่า $z = f(x,y)$ ผลลัพธ์คือ **ผิว (surface)** ในปริภูมิสามมิติ ปัญหาคือเราวาดผิวสามมิติบนกระดาษด้วยดินสอไม่ได้ดี และอ่านค่าจากภาพผิวก็ยากมาก

วิธีแก้คือ **contour** หรือ **level curve** ซึ่งเป็นเทคนิคเดียวกับแผนที่ภูมิประเทศที่เขียนเส้นความสูงเท่ากันไว้ แนวคิดคือ แทนที่จะวาดผิวทั้งผิว เราเลือกค่าคงตัว $c$ มาสองสามค่า แล้วถามว่า "จุด $(x,y)$ ไหนที่ทำให้ $f(x,y)$ เท่ากับ $c$ พอดี"

$$
\text{level curve ที่ระดับ } c \;=\; \{\, (x,y) \in D \;:\; f(x,y) = c \,\}
$$

สิ่งที่ได้คือเส้นโค้งในระนาบ $xy$ ธรรมดา วาดด้วยดินสอได้ และเมื่อวาดหลายระดับซ้อนกันบนภาพเดียว เราจะอ่านรูปร่างของผิวออกได้ทันที **นี่ไม่ใช่ภาพประกอบ นี่คือเครื่องมือคำนวณ** เพราะทุกอย่างที่สำคัญในสัปดาห์นี้และสัปดาห์ 5 อ่านออกจากภาพ contour ได้

มีข้อสังเกตเชิงเรขาคณิตข้อหนึ่งที่ต้องจำให้แม่นตั้งแต่ตอนนี้ เพราะจะกลับมาเป็นหัวใจของหัวข้อ 3

> **เส้น contour ที่อยู่ชิดกัน หมายถึงผิวชัน** เพราะเดินไปไม่ไกลค่าก็เปลี่ยนไปหนึ่งขั้นแล้ว
> **เส้น contour ที่ห่างกัน หมายถึงผิวแบน** เพราะต้องเดินไกลค่าจึงเปลี่ยนไปหนึ่งขั้น

## 1.2 ตัวอย่างที่ 1 — contour ของชามกลม *(ตรงไปตรงมา)*

**โจทย์:** ให้ $f(x,y) = x^2 + y^2$ จงหา $f(3,4)$, $f(0,5)$, $f(-3,-4)$ แล้วเขียน level curve ที่ระดับ $c = 1, 4, 9$

$$
\begin{aligned}
f(3,4) &= 3^2 + 4^2 = 9 + 16 = 25 && \text{แทน } x=3,\; y=4 \\
f(0,5) &= 0^2 + 5^2 = 0 + 25 = 25 && \text{แทน } x=0,\; y=5 \\
f(-3,-4) &= (-3)^2 + (-4)^2 = 9 + 16 = 25 && \text{แทน } x=-3,\; y=-4
\end{aligned}
$$

จุดสามจุดนี้ต่างกันคนละที่ในระนาบ แต่ให้ค่าฟังก์ชันเท่ากันหมด คือ $25$ ทั้งสามจุดจึงอยู่บน level curve เดียวกัน คือระดับ $c = 25$

ต่อไปเขียน level curve ตามที่โจทย์ขอ

$$
\begin{aligned}
c = 1:\quad x^2 + y^2 &= 1 && \text{วงกลมศูนย์กลาง } (0,0) \text{ รัศมี } \sqrt{1} = 1 \\
c = 4:\quad x^2 + y^2 &= 4 && \text{วงกลมรัศมี } \sqrt{4} = 2 \\
c = 9:\quad x^2 + y^2 &= 9 && \text{วงกลมรัศมี } \sqrt{9} = 3
\end{aligned}
$$

**ตรวจคำตอบ:** หยิบจุดหนึ่งจุดจากแต่ละวง แล้วแทนกลับเข้าฟังก์ชันตั้งต้น จุด $(1,0)$ ให้ $f = 1 + 0 = 1$ อยู่บนวง $c=1$ จริง · จุด $(0,2)$ ให้ $f = 0 + 4 = 4$ อยู่บนวง $c=4$ จริง · จุด $(0,3)$ ให้ $f = 0 + 9 = 9$ อยู่บนวง $c=9$ จริง

**อ่านความชันจากภาพ:** รัศมีของสามวงเป็น $1, 2, 3$ ระยะห่างระหว่างวงจึงเท่ากันคือ $1$ หน่วย ทั้งที่ค่าที่เพิ่มขึ้นไม่เท่ากัน ($1 \to 4$ เพิ่ม 3 แต่ $4 \to 9$ เพิ่ม 5) แปลว่ายิ่งออกห่างจากจุดกำเนิด ผิวยิ่งชัน ซึ่งตรงกับรูปชามที่ขอบชันกว่าก้นชาม

**ตอบ:** $f(3,4) = f(0,5) = f(-3,-4) = 25$ · level curve ทั้งสามระดับเป็นวงกลมศูนย์กลางที่จุดกำเนิด รัศมี $1, 2, 3$ ตามลำดับ

[FIGURE | A | w04_f01_contour_circles | แกน x และ y ตั้งฉากกันแบบเรียบ ๆ ขาวดำ มีวงกลมสามวงศูนย์กลางร่วมที่จุดกำเนิด รัศมี 1, 2, 3 เขียนป้าย c=1, c=4, c=9 กำกับแต่ละวงไว้ที่ด้านขวาของวง มีจุดทึบสามจุดที่ (3,4), (0,5), (-3,-4) พร้อมป้าย f=25 ทั้งสามจุด และมีวงกลมประรัศมี 5 ลากผ่านสามจุดนั้น เส้นน้อย ไม่ระบายสี วาดตามด้วยดินสอได้]

## 1.3 ตัวอย่างที่ 2 — contour ที่ไม่กลม และการอ่านความชันจากระยะห่าง *(มีชั้นเชิงเพิ่ม)*

ตัวอย่างนี้ต่างจากตัวแรกสองอย่าง หนึ่งคือ level curve ไม่ใช่วงกลม จึงต้อง **จัดรูปให้เป็นรูปมาตรฐานก่อน** จึงจะรู้ว่าต้องวาดอะไร สองคือระยะห่างระหว่างเส้นในสองทิศทางไม่เท่ากัน ซึ่งจะให้ข้อมูลที่ตัวอย่างแรกไม่มี

**โจทย์:** ให้ $f(x,y) = x^2 + 4y^2$ จงเขียน level curve ที่ระดับ $c = 4, 16, 36$ และเปรียบเทียบระยะห่างของเส้นในทิศ $x$ กับทิศ $y$

$$
\begin{aligned}
c = 4:\quad x^2 + 4y^2 &= 4 && \text{หารทั้งสองข้างด้วย } 4 \\
\frac{x^2}{4} + \frac{y^2}{1} &= 1 && \text{วงรี ครึ่งแกนแนว } x = 2,\; \text{ครึ่งแกนแนว } y = 1 \\[4pt]
c = 16:\quad x^2 + 4y^2 &= 16 && \text{หารด้วย } 16 \\
\frac{x^2}{16} + \frac{y^2}{4} &= 1 && \text{ครึ่งแกนแนว } x = 4,\; \text{แนว } y = 2 \\[4pt]
c = 36:\quad x^2 + 4y^2 &= 36 && \text{หารด้วย } 36 \\
\frac{x^2}{36} + \frac{y^2}{9} &= 1 && \text{ครึ่งแกนแนว } x = 6,\; \text{แนว } y = 3
\end{aligned}
$$

ตอนนี้เทียบระยะห่างของเส้นทั้งสามในสองทิศทาง

$$
\begin{aligned}
\text{บนแกน } x:\quad & x = 2,\; 4,\; 6 && \text{ระยะห่าง } 2 \text{ และ } 2 \\
\text{บนแกน } y:\quad & y = 1,\; 2,\; 3 && \text{ระยะห่าง } 1 \text{ และ } 1
\end{aligned}
$$

**ตรวจคำตอบ:** แทนจุดปลายแกนกลับเข้าฟังก์ชัน จุด $(2,0)$ ให้ $f = 4 + 0 = 4$ ✓ · จุด $(0,1)$ ให้ $f = 0 + 4 = 4$ ✓ ทั้งสองจุดอยู่บนวงรี $c = 4$ จริง · จุด $(0,3)$ ให้ $f = 0 + 4(9) = 36$ ✓

**สิ่งที่อ่านได้:** เส้น contour ในทิศ $y$ ชิดกันเป็นสองเท่าของทิศ $x$ (ห่างกัน 1 เทียบกับ 2) แปลว่า **ยืนที่จุดหนึ่งแล้วเดินไปทาง $y$ ค่าจะพุ่งเร็วกว่าเดินไปทาง $x$** ผิวนี้ชันในทิศ $y$ มากกว่าทิศ $x$ ข้อสรุปนี้เราอ่านได้จากภาพเพียว ๆ โดยยังไม่รู้จักอนุพันธ์ย่อยเลย และในหัวข้อ 2 เราจะเห็นว่าตัวเลขที่ยืนยันข้อสรุปนี้คือ $f_x = 2x$ กับ $f_y = 8y$ ซึ่งบอกว่าทิศ $y$ ไวกว่าจริง

**ตอบ:** level curve ทั้งสามระดับเป็นวงรีศูนย์กลางที่จุดกำเนิด แกนยาวอยู่แนว $x$ · เส้นชิดกันในทิศ $y$ มากกว่าทิศ $x$ สองเท่า จึงชันในทิศ $y$ มากกว่า

## 1.4 ตัวอย่างที่ 3 — level curve ที่ไม่เป็นเส้นโค้งและที่ขาดเป็นสองท่อน *(ผลลัพธ์ผิดคาด — มีแต่ใน note)*

คำว่า "level **curve**" ทำให้เราคาดว่าผลลัพธ์จะเป็นเส้นโค้งเรียบ ๆ หนึ่งเส้นเสมอ ตัวอย่างนี้จะแสดงว่าไม่จริงทั้งสองข้อ

**โจทย์:** ให้ $f(x,y) = xy$ จงหา level set ที่ระดับ $c = 6$, $c = -6$ และ $c = 0$

$$
\begin{aligned}
c = 6:\quad xy &= 6 && \Rightarrow\; y = \frac{6}{x} \quad (x \ne 0) \\
c = -6:\quad xy &= -6 && \Rightarrow\; y = -\frac{6}{x} \quad (x \ne 0) \\
c = 0:\quad xy &= 0 && \Rightarrow\; x = 0 \;\text{ หรือ }\; y = 0
\end{aligned}
$$

พิจารณาทีละระดับ

$$
\begin{aligned}
c = 6:\quad & (2,3),\; (3,2),\; (1,6),\; (6,1) && \text{อยู่ในจตุภาคที่ 1} \\
& (-2,-3),\; (-3,-2),\; (-1,-6) && \text{อยู่ในจตุภาคที่ 3} \\[4pt]
c = 0:\quad & (0, 5),\; (0,-1),\; (0, 100) && \text{ทุกจุดบนแกน } y \\
& (5, 0),\; (-1, 0),\; (100, 0) && \text{ทุกจุดบนแกน } x
\end{aligned}
$$

**ตรวจคำตอบ:** $f(2,3) = 2 \cdot 3 = 6$ ✓ · $f(-2,-3) = (-2)(-3) = 6$ ✓ · $f(0,100) = 0 \cdot 100 = 0$ ✓ · $f(100,0) = 100 \cdot 0 = 0$ ✓

**สิ่งที่เกิดขึ้น:** ผลลัพธ์ผิดคาดสองข้อ

ข้อแรก **level set ที่ระดับ $c = 6$ ขาดเป็นสองท่อนที่ไม่ต่อกัน** ท่อนหนึ่งอยู่ในจตุภาคที่ 1 อีกท่อนอยู่ในจตุภาคที่ 3 และไม่มีทางเดินจากท่อนหนึ่งไปอีกท่อนโดยที่ค่า $f$ ยังเท่ากับ 6 ตลอดทาง ฉะนั้น "เส้นระดับหนึ่งเส้น" อาจมีหลายชิ้นได้

ข้อสอง **level set ที่ระดับ $c = 0$ ไม่ใช่เส้นโค้ง มันคือสองเส้นตรงที่ตัดกัน** คือแกน $x$ ทั้งแกนรวมกับแกน $y$ ทั้งแกน และจุดที่มันตัดกันคือจุดกำเนิด ที่จุดนั้นเราถามคำถามที่เคยตอบได้ง่ายแล้วตอบไม่ได้ทันที คือ "เส้นสัมผัสของ level curve ที่จุดกำเนิดคือเส้นไหน" — มีสองเส้นให้เลือก และไม่มีเหตุผลจะเลือกเส้นใดเส้นหนึ่ง

ข้อสองนี้สำคัญมาก เพราะในหัวข้อ 3 เราจะบอกว่า "เกรเดียนต์ตั้งฉากกับ level curve" ประโยคนั้นจะพูดไม่ได้ที่จุดซึ่ง level set ตัดกันเอง และจุดแบบนั้นไม่ใช่จุดหายาก — เราจะเจอมันอีกครั้งในตัวอย่างที่ 3 ของหัวข้อ 3 พร้อมกับเหตุผลว่าทำไมจุดพวกนั้นน่าสนใจเป็นพิเศษ

**ตอบ:** $c = 6$ ได้ไฮเพอร์โบลาสองท่อนในจตุภาค 1 และ 3 · $c = -6$ ได้สองท่อนในจตุภาค 2 และ 4 · $c = 0$ ได้แกน $x$ รวมกับแกน $y$ ซึ่งเป็นเส้นตรงสองเส้นตัดกันที่จุดกำเนิด ไม่ใช่เส้นโค้งเรียบ

[FIGURE | A | w04_f03_level_set_xy_degenerate | แกน x และ y แบบเรียบขาวดำ วาดไฮเพอร์โบลาสี่ท่อน ท่อนในจตุภาค 1 และ 3 เป็นเส้นทึบมีป้าย c=6 ท่อนในจตุภาค 2 และ 4 เป็นเส้นประมีป้าย c=-6 ทับบนแกน x และแกน y ให้ลากเส้นหนาพิเศษพร้อมป้าย c=0 และวงกลมเน้นที่จุดกำเนิดพร้อมข้อความกำกับ "ที่จุดนี้ level set ตัดกันเอง เส้นสัมผัสไม่มีเส้นเดียว" มีจุดทึบที่ (2,3) และ (-2,-3) กำกับว่าอยู่ระดับเดียวกัน]

## 1.5 ตัวอย่างจริงที่จะใช้ทั้งสัปดาห์ — loss function $L(w,b)$

หัวข้อนี้ไม่ใช่ตัวอย่างเพิ่ม แต่เป็นการตั้งของจริงที่จะใช้ตลอดสามหัวข้อที่เหลือ ขอให้อ่านช้า ๆ

สมมติเรามีข้อมูลสามจุด

$$
(x_1, y_1) = (1, 2), \qquad (x_2, y_2) = (2, 3), \qquad (x_3, y_3) = (3, 5)
$$

เราต้องการฟิตเส้นตรง $\hat{y} = wx + b$ ให้ผ่านใกล้ทั้งสามจุดที่สุด สำหรับเส้นหนึ่งเส้น เราวัดความเลวด้วยผลรวมกำลังสองของส่วนต่างระหว่างค่าจริงกับค่าที่เส้นทำนาย

$$
L(w, b) \;=\; \sum_{i=1}^{3} \big(y_i - w x_i - b\big)^2 \;=\; (2 - w - b)^2 + (3 - 2w - b)^2 + (5 - 3w - b)^2
$$

**นี่คือฟังก์ชันสองตัวแปรที่แท้จริง** ตัวแปรของมันไม่ใช่ $x$ กับ $y$ ที่เป็นข้อมูล — ข้อมูลถูกแทนเลขลงไปแล้วและกลายเป็นค่าคงตัวไปแล้ว ตัวแปรของมันคือ $w$ กับ $b$ ซึ่งเป็นสิ่งที่เราปรับได้ ประโยคนี้เป็นจุดที่คนสับสนมากที่สุดในสัปดาห์นี้ ขอให้อ่านซ้ำ

ลองคำนวณค่า $L$ ที่พารามิเตอร์สามชุด

$$
\begin{aligned}
(w,b) = (1,1):\quad L &= (2-1-1)^2 + (3-2-1)^2 + (5-3-1)^2 \\
&= 0^2 + 0^2 + 1^2 = 1 \\[4pt]
(w,b) = (1,0):\quad L &= (2-1-0)^2 + (3-2-0)^2 + (5-3-0)^2 \\
&= 1^2 + 1^2 + 2^2 = 1 + 1 + 4 = 6 \\[4pt]
(w,b) = (2,0):\quad L &= (2-2-0)^2 + (3-4-0)^2 + (5-6-0)^2 \\
&= 0^2 + (-1)^2 + (-1)^2 = 0 + 1 + 1 = 2
\end{aligned}
$$

อ่านผลได้ทันทีว่าเส้น $\hat y = x + 1$ (ค่า $L = 1$) ดีกว่าเส้น $\hat y = 2x$ (ค่า $L = 2$) และดีกว่าเส้น $\hat y = x$ (ค่า $L = 6$) มาก

ต่อไปกระจาย $L$ ออกมาให้เห็นหน้าตาจริง เพราะเราจะใช้รูปกระจายนี้ในหัวข้อ 2

$$
\begin{aligned}
(2-w-b)^2 &= 4 + w^2 + b^2 - 4w - 4b + 2wb \\
(3-2w-b)^2 &= 9 + 4w^2 + b^2 - 12w - 6b + 4wb \\
(5-3w-b)^2 &= 25 + 9w^2 + b^2 - 30w - 10b + 6wb \\ \hline
L(w,b) &= 14w^2 + 3b^2 + 12wb - 46w - 20b + 38
\end{aligned}
$$

**ตรวจคำตอบ:** แทน $(w,b) = (1,1)$ ลงในรูปกระจาย ได้ $14 + 3 + 12 - 46 - 20 + 38 = 1$ ✓ ตรงกับที่คำนวณจากรูปผลรวมกำลังสองข้างบน · แทน $(w,b) = (2,0)$ ได้ $14(4) + 0 + 0 - 92 - 0 + 38 = 56 - 92 + 38 = 2$ ✓

สังเกตสองข้อจากรูปกระจาย ข้อแรก $L$ เป็น **พหุนามกำลังสอง** ใน $w$ และ $b$ ไม่มีพจน์กำลังสามหรือสูงกว่า ข้อสอง มีพจน์ $12wb$ อยู่ พจน์นี้เรียกว่าพจน์ปฏิสัมพันธ์ (interaction term) มันคือสาเหตุที่ level curve ของ $L$ เป็นวงรีที่ **เอียง** ไม่ใช่วงรีที่แกนตรงกับแกน $w$ และ $b$ และมันจะกลับมามีบทบาทตอนเราหาอนุพันธ์ย่อยผสม

การวาด level curve ของ $L$ จึงให้ภาพที่เรียกว่า **loss landscape** เป็นวงรีเอียงซ้อนกันหลายชั้น วงในสุดคือพารามิเตอร์ที่ดีที่สุด และงานของ Data Science ทั้งหมด — พูดแบบไม่เกินจริงเลย — คือการหาว่าจุดกลางวงในสุดนั้นอยู่ที่ไหน

[FIGURE | B | w04_f04_loss_landscape_wb | แผนที่ contour ของ L(w,b)=14w^2+3b^2+12wb-46w-20b+38 บนระนาบที่แกนนอนเป็น w และแกนตั้งเป็น b ช่วง w จาก 0 ถึง 3 และ b จาก -1 ถึง 3 วาดวงรีเอียงซ้อนกันสี่ห้าชั้นพร้อมป้ายระดับ L=1, L=2, L=6, L=12 มีจุดทึบสามจุดกำกับชื่อคือ (1,1) ป้าย L=1 · (2,0) ป้าย L=2 · (1,0) ป้าย L=6 และมีเครื่องหมายกากบาทเล็ก ๆ ตรงกลางวงในสุดพร้อมข้อความ "จุดที่ยังไม่หา — สัปดาห์ 5"]

## 1.7 ใช้ทำอะไรใน DS/CS

ทุกครั้งที่มีคนแสดงกราฟ "การเทรนโมเดล" สิ่งที่เขาแสดงคือการเดินทางของจุดหนึ่งจุดบนแผนที่ contour ของ loss function จุดเริ่มต้นคือค่าพารามิเตอร์ตั้งต้น จุดปลายทางที่หวังไว้คือกลางวงในสุด และเส้นทางที่จุดนั้นเดินคือสิ่งที่อัลกอริทึมเลือก ถ้าอ่าน contour ไม่เป็น กราฟเหล่านั้นก็เป็นเพียงภาพสวย

ประโยชน์ที่จับต้องได้ที่สุดคือ **รูปร่างของ contour บอกว่าปัญหานั้นยากหรือง่าย** ถ้า level curve เป็นวงกลมเกือบกลม การเดินลงไปหาจุดต่ำสุดง่ายเพราะทุกทิศทางมีมาตรฐานเดียวกัน แต่ถ้า level curve เป็นวงรีแบนยาวเหมือนหุบเขาแคบ การเดินจะเซไปเซมาข้ามหุบเขาแทนที่จะเดินลงตามหุบเขา นี่คือเหตุผลจริงที่วิชา Data Science มีขั้นตอนชื่อ **feature scaling** — การปรับสเกลข้อมูลให้ตัวแปรทุกตัวมีช่วงใกล้กัน มีผลตรง ๆ คือทำให้วงรีแบนยาวกลายเป็นวงกลมมากขึ้น และแผนที่ที่กลมกว่าคือแผนที่ที่เดินง่ายกว่า ประเด็นนี้เป็นเรขาคณิตล้วน ๆ ไม่ใช่เรื่องของโค้ด

อีกเรื่องคือคำว่า **ridge** และ **plateau** ที่ได้ยินในรายงานผลการทดลอง ทั้งสองคำเป็นคำเชิงภูมิประเทศ และมีความหมายบน contour ตรงตัว plateau คือบริเวณที่เส้น contour ห่างกันมาก แปลว่าผิวแบน ค่าแทบไม่เปลี่ยน แปลว่าอัลกอริทึมจะเดินช้ามาก ridge คือสันที่เส้น contour ชิดกันด้านหนึ่งและห่างด้านหนึ่ง การอ่านสองคำนี้ออกจากภาพเป็นทักษะเดียวกับที่ฝึกในหัวข้อนี้

# 2. อนุพันธ์ย่อย

*(ตรงกับแถวที่ 2 ในตาราง 180 นาที — Lecture 70 นาที · นี่คือแกนของสัปดาห์)*

## 2.1 หลักการ

สัปดาห์ 3 เราตอบคำถาม "ถ้าขยับ $x$ ไปเล็กน้อย ค่า $f$ เปลี่ยนเร็วแค่ไหน" ด้วยตัวเลขตัวเดียวคือ $f'(x)$ เพราะบนเส้นโค้งมีทิศให้ขยับแค่ทางเดียว บนผิวสองตัวแปรคำถามนี้ตอบด้วยตัวเลขตัวเดียวไม่ได้ เพราะยืนอยู่บนผิวแล้วขยับได้รอบทิศ ค่าจะเปลี่ยนเร็วแค่ไหนขึ้นกับว่าเราขยับไปทางไหน

ทางออกที่เรียบง่ายและได้ผลคือ **อย่าถามทุกทิศ ถามแค่สองทิศ** คือทิศขนานแกน $x$ และทิศขนานแกน $y$ วิธีถามคือ **ตรึงตัวแปรอีกตัวไว้ให้เป็นค่าคงตัว** แล้วปัญหาจะยุบกลับเป็นปัญหาหนึ่งตัวแปรที่เราทำเป็นแล้วทั้งหมดจากสัปดาห์ 3

**นิยาม (อนุพันธ์ย่อยเทียบ $x$):** ตรึง $y$ ไว้ที่ค่าคงตัว แล้วหาอนุพันธ์ของสิ่งที่เหลือเทียบ $x$ ตามปกติ

$$
f_x(x,y) \;=\; \frac{\partial f}{\partial x} \;=\; \lim_{h \to 0} \frac{f(x + h,\; y) - f(x,\; y)}{h}
$$

**นิยาม (อนุพันธ์ย่อยเทียบ $y$):** ตรึง $x$ ไว้ แล้วหาอนุพันธ์เทียบ $y$

$$
f_y(x,y) \;=\; \frac{\partial f}{\partial y} \;=\; \lim_{h \to 0} \frac{f(x,\; y + h) - f(x,\; y)}{h}
$$

สังเกตว่าในนิยามแรก ช่อง $y$ **ไม่ขยับเลย** ทั้งในตัวตั้งและตัวลบ ส่วนในนิยามที่สอง ช่อง $x$ ไม่ขยับเลย นี่คือความหมายของคำว่า "ตรึง" อย่างเป็นทางการ และเป็นเหตุผลที่สัญลักษณ์เปลี่ยนจาก $d$ เป็น $\partial$ — เครื่องหมาย $\partial$ อ่านว่า "พาร์เชียล" และมันเตือนว่าเรากำลังดูการเปลี่ยนแปลงเพียง **บางส่วน** ของทั้งหมดที่เป็นไปได้

**ความหมายเชิงเรขาคณิต** อ่านได้จาก contour ได้ตรง ๆ การตรึง $y = b$ คือการเลือก **เส้นแนวนอนหนึ่งเส้น** บนแผนที่ contour แล้วเดินไปตามเส้นนั้น ค่าที่ได้ตลอดทางเป็นฟังก์ชันหนึ่งตัวแปร เขียนว่า $g(x) = f(x, b)$ กราฟของ $g$ เรียกว่า **กราฟหน้าตัด (trace)** และ

$$
f_x(a, b) \;=\; g'(a) \qquad\text{เมื่อ}\qquad g(x) = f(x, b)
$$

นี่คือการปิดวงกับสัปดาห์ 3 อย่างตรงไปตรงมาที่สุด **$f_x(a,b)$ ไม่ใช่ของใหม่ มันคือความชันเส้นสัมผัสของเส้นโค้งหนึ่งตัวแปรที่เราหาเป็นแล้ว** เพียงแต่เส้นโค้งนั้นได้มาจากการเฉือนผิวด้วยระนาบ

**วิธีปฏิบัติ** ก่อนหาอนุพันธ์ย่อยทุกครั้ง ให้เขียนบรรทัดนี้ก่อนลงมือเสมอ

> ตรึง $y$ ไว้ ถือ $y$ เป็นค่าคงตัวเหมือนเลข 7

เขียนบรรทัดนี้ออกมาจริง ๆ ไม่ใช่นึกในใจ เพราะความผิดพลาดเกือบทั้งหมดในสัปดาห์นี้เกิดจากการเผลอหาอนุพันธ์ของตัวแปรที่ตรึงไว้ และการเขียนออกมาเป็นวัคซีนที่ได้ผลจริง

ตารางเทียบสั้น ๆ ที่ควรจำ เมื่อ **ตรึง $y$**

| นิพจน์ | อนุพันธ์เทียบ $x$ | เหตุผล |
|---|---|---|
| $y$ | $0$ | เป็นค่าคงตัว |
| $y^5$ | $0$ | ค่าคงตัวยกกำลังก็ยังเป็นค่าคงตัว |
| $xy$ | $y$ | คือ (ค่าคงตัว) $\times\, x$ |

## 2.2 ตัวอย่างที่ 1 — พหุนามตรง ๆ *(ตรงไปตรงมา)*

**โจทย์:** ให้ $f(x,y) = 3x^2 y + 5y^3 - 4x$ จงหา $f_x(2,1)$ และ $f_y(2,1)$

หา $f_x$ ก่อน **ตรึง $y$ ไว้ ถือ $y$ เป็นค่าคงตัว**

$$
\begin{aligned}
f_x &= \frac{\partial}{\partial x}\big(3x^2 y\big) + \frac{\partial}{\partial x}\big(5y^3\big) - \frac{\partial}{\partial x}\big(4x\big) && \text{แยกทีละพจน์} \\
&= 3y \cdot \frac{\partial}{\partial x}\big(x^2\big) + 0 - 4 && 5y^3 \text{ ไม่มี } x \text{ จึงเป็น } 0 \\
&= 3y \cdot 2x - 4 && \text{power rule} \\
&= 6xy - 4 && \\
f_x(2,1) &= 6(2)(1) - 4 = 12 - 4 = 8 && \text{แทน } x=2,\; y=1
\end{aligned}
$$

ต่อไปหา $f_y$ **ตรึง $x$ ไว้ ถือ $x$ เป็นค่าคงตัว**

$$
\begin{aligned}
f_y &= \frac{\partial}{\partial y}\big(3x^2 y\big) + \frac{\partial}{\partial y}\big(5y^3\big) - \frac{\partial}{\partial y}\big(4x\big) && \text{แยกทีละพจน์} \\
&= 3x^2 \cdot 1 + 5 \cdot 3y^2 - 0 && -4x \text{ ไม่มี } y \text{ จึงเป็น } 0 \\
&= 3x^2 + 15y^2 && \\
f_y(2,1) &= 3(4) + 15(1) = 12 + 15 = 27 && \text{แทน } x=2,\; y=1
\end{aligned}
$$

**ตรวจคำตอบ:** ตรวจ $f_x(2,1)$ ด้วยวิธีกราฟหน้าตัด ตรึง $y = 1$ ก่อนแล้วค่อยหาอนุพันธ์ ได้ $g(x) = f(x,1) = 3x^2 + 5 - 4x$ ซึ่งเป็นฟังก์ชันหนึ่งตัวแปรธรรมดา $g'(x) = 6x - 4$ และ $g'(2) = 12 - 4 = 8$ ✓ ตรงกัน · ตรวจ $f_y(2,1)$ แบบเดียวกัน ตรึง $x = 2$ ได้ $h(y) = f(2,y) = 12y + 5y^3 - 8$ ดังนั้น $h'(y) = 12 + 15y^2$ และ $h'(1) = 27$ ✓

**ตอบ:** $f_x(2,1) = 8$ และ $f_y(2,1) = 27$

**ข้อสังเกต:** วิธีตรวจคำตอบที่ใช้ข้างบนคือ **ตรึงก่อนแล้วค่อยหาอนุพันธ์** เทียบกับวิธีทำหลักซึ่งคือ **หาอนุพันธ์ก่อนแล้วค่อยแทนค่า** สองวิธีนี้ต้องได้คำตอบเดียวกันเสมอ ใช้เป็นเครื่องตรวจได้ทุกข้อ

## 2.3 ตัวอย่างที่ 2 — ต้องใช้ product rule และกฎลูกโซ่ในตัวแปรที่ตรึงไว้ *(มีชั้นเชิงเพิ่ม)*

ตัวอย่างนี้ยากกว่าตัวแรกสองชั้น ชั้นแรกคือ $x$ ปรากฏสองที่ในพจน์เดียว จึงต้องใช้ product rule ชั้นสองคือเลขชี้กำลังมี $x$ อยู่ข้างใน จึงต้องใช้กฎลูกโซ่ และตอนใช้กฎลูกโซ่ต้องระวังว่า อนุพันธ์ของ $xy$ เทียบ $x$ คือ $y$ ไม่ใช่ $1$ และไม่ใช่ $0$

**โจทย์:** ให้ $f(x,y) = x^2 e^{xy}$ จงหา $f_x(3,0)$ และ $f_y(3,0)$

หา $f_x$ **ตรึง $y$ ไว้ ถือ $y$ เป็นค่าคงตัว** พจน์นี้เป็นผลคูณของ $x^2$ กับ $e^{xy}$ ซึ่งทั้งสองก้อนมี $x$

$$
\begin{aligned}
f_x &= \frac{\partial}{\partial x}\big(x^2\big) \cdot e^{xy} + x^2 \cdot \frac{\partial}{\partial x}\big(e^{xy}\big) && \text{product rule} \\
&= 2x \cdot e^{xy} + x^2 \cdot e^{xy} \cdot \frac{\partial}{\partial x}(xy) && \text{กฎลูกโซ่ที่ก้อนที่สอง} \\
&= 2x\,e^{xy} + x^2 e^{xy} \cdot y && \frac{\partial}{\partial x}(xy) = y \text{ เพราะ } y \text{ ถูกตรึง} \\
&= e^{xy}\big(2x + x^2 y\big) && \text{ดึง } e^{xy} \text{ ออกมา} \\
f_x(3,0) &= e^{3 \cdot 0}\big(2(3) + 9(0)\big) && \text{แทน } x=3,\; y=0 \\
&= e^{0}(6 + 0) = 1 \cdot 6 = 6 && e^0 = 1
\end{aligned}
$$

หา $f_y$ **ตรึง $x$ ไว้ ถือ $x$ เป็นค่าคงตัว** ตอนนี้ $x^2$ เป็นเพียงสัมประสิทธิ์ ไม่ต้องใช้ product rule เลย

$$
\begin{aligned}
f_y &= x^2 \cdot \frac{\partial}{\partial y}\big(e^{xy}\big) && x^2 \text{ เป็นค่าคงตัว} \\
&= x^2 \cdot e^{xy} \cdot \frac{\partial}{\partial y}(xy) && \text{กฎลูกโซ่} \\
&= x^2 e^{xy} \cdot x && \frac{\partial}{\partial y}(xy) = x \text{ เพราะ } x \text{ ถูกตรึง} \\
&= x^3 e^{xy} && \\
f_y(3,0) &= 27 \cdot e^{0} = 27 \cdot 1 = 27 && \text{แทน } x=3,\; y=0
\end{aligned}
$$

**ตรวจคำตอบ:** ตรวจ $f_y(3,0)$ ด้วยวิธีตรึงก่อน ตรึง $x = 3$ ได้ $h(y) = 9 e^{3y}$ ดังนั้น $h'(y) = 9 \cdot 3 e^{3y} = 27 e^{3y}$ และ $h'(0) = 27 \cdot 1 = 27$ ✓ · ตรวจ $f_x(3,0)$ ด้วยวิธีตรึงก่อน ตรึง $y = 0$ ได้ $g(x) = x^2 e^{0} = x^2$ ดังนั้น $g'(x) = 2x$ และ $g'(3) = 6$ ✓

**ตอบ:** $f_x(3,0) = 6$ และ $f_y(3,0) = 27$

**สิ่งที่ต้องเก็บไปจากตัวอย่างนี้:** งานหนักที่สุดคือบรรทัด $\frac{\partial}{\partial x}(xy) = y$ นักศึกษาส่วนใหญ่ที่ผิดข้อแบบนี้ผิดเพราะเขียน $\frac{\partial}{\partial x}(xy) = 1$ (ลืม $y$) หรือเขียน $= 0$ (คิดว่า $xy$ ทั้งก้อนเป็นค่าคงตัว) ทางกันคือ **เขียน $xy$ ใหม่เป็น $y \cdot x$ ก่อน** แล้วจะเห็นชัดว่าเป็นค่าคงตัวคูณ $x$ อนุพันธ์คือค่าคงตัวนั้น

## 2.4 ตัวอย่างที่ 3 — อนุพันธ์ย่อยตัวหนึ่งเป็นศูนย์ทุกจุด *(ผลลัพธ์ผิดคาด — มีแต่ใน note)*

เราคุ้นกับความคิดว่า ถ้าสูตรของฟังก์ชันมีตัวแปร $y$ อยู่ ค่าของฟังก์ชันย่อมต้องเปลี่ยนเมื่อ $y$ เปลี่ยน ตัวอย่างนี้แสดงว่าความคิดนั้นผิด

**โจทย์:** ให้ $f(x,y) = \dfrac{x^3 + xy^2}{x^2 + y^2}$ สำหรับ $(x,y) \ne (0,0)$ จงหา $f_y$ และหา $f_x(5, 7)$

หา $f_y$ ตรง ๆ ด้วย quotient rule ก่อน **ตรึง $x$ ไว้** ให้ $u = x^3 + xy^2$ และ $v = x^2 + y^2$

$$
\begin{aligned}
\frac{\partial u}{\partial y} &= 0 + x \cdot 2y = 2xy && x^3 \text{ เป็นค่าคงตัว} \\
\frac{\partial v}{\partial y} &= 0 + 2y = 2y && x^2 \text{ เป็นค่าคงตัว} \\[4pt]
f_y &= \frac{v \cdot u_y - u \cdot v_y}{v^2} && \text{quotient rule} \\
&= \frac{(x^2+y^2)(2xy) - (x^3 + xy^2)(2y)}{(x^2+y^2)^2} && \text{แทนค่า} \\
&= \frac{(x^2+y^2)(2xy) - x(x^2 + y^2)(2y)}{(x^2+y^2)^2} && \text{แยกตัวประกอบตัวตั้ง: } x^3+xy^2 = x(x^2+y^2) \\
&= \frac{(x^2+y^2)\big(2xy - 2xy\big)}{(x^2+y^2)^2} && \text{ดึง } (x^2+y^2) \text{ ออกมา} \\
&= \frac{(x^2+y^2) \cdot 0}{(x^2+y^2)^2} = 0 &&
\end{aligned}
$$

ได้ $f_y = 0$ **ทุกจุดในโดเมน** ไม่ใช่แค่ที่จุดใดจุดหนึ่ง

ต่อไปหาสาเหตุ ลองย่อฟังก์ชันตั้งต้น

$$
\begin{aligned}
f(x,y) &= \frac{x^3 + xy^2}{x^2+y^2} && \\
&= \frac{x\big(x^2 + y^2\big)}{x^2 + y^2} && \text{แยกตัวประกอบ } x \text{ ออกจากตัวตั้ง} \\
&= x && \text{ตัด } (x^2+y^2) \text{ ได้เพราะไม่เป็นศูนย์ในโดเมน}
\end{aligned}
$$

ฟังก์ชันนี้คือ $f(x,y) = x$ มาตั้งแต่ต้น เพียงแต่ถูกเขียนอำพรางไว้ ดังนั้น

$$
f_x = \frac{\partial}{\partial x}(x) = 1 \qquad\text{ทุกจุด}\qquad\Rightarrow\qquad f_x(5,7) = 1
$$

**ตรวจคำตอบ:** แทนตัวเลขลงในรูปเดิมเพื่อยืนยันว่า $f = x$ จริง $f(5,7) = \dfrac{125 + 5 \cdot 49}{25 + 49} = \dfrac{125 + 245}{74} = \dfrac{370}{74} = 5$ ✓ เท่ากับ $x = 5$ · และ $f(5, 1) = \dfrac{125 + 5}{25+1} = \dfrac{130}{26} = 5$ ✓ ค่าเท่าเดิมทั้งที่ $y$ เปลี่ยนจาก 7 เป็น 1 ซึ่งยืนยัน $f_y = 0$ ด้วยตัวเลขจริง

**สิ่งที่เกิดขึ้น:** ตัวแปร $y$ ปรากฏสี่ที่ในสูตรตั้งต้น แต่ฟังก์ชัน **ไม่ขึ้นกับ $y$ เลย** เพราะ $y$ ในตัวตั้งและตัวส่วนตัดกันหมด บทเรียนมีสองข้อ

ข้อแรก **"ตัวแปรอยู่ในสูตร" ไม่เท่ากับ "ฟังก์ชันขึ้นกับตัวแปรนั้น"** อนุพันธ์ย่อยที่เป็นศูนย์ตลอดเป็นหลักฐานว่าตัวแปรนั้นไม่มีผลจริง

ข้อสอง ในทางปฏิบัติ **ถ้าย่อรูปได้ ให้ย่อก่อนหาอนุพันธ์** งาน quotient rule เจ็ดบรรทัดข้างบนหายไปทั้งหมดถ้าเห็นตั้งแต่แรกว่า $f = x$ นิสัยนี้จะช่วยมากตอนสัปดาห์ 5 ที่นิพจน์ยาวขึ้น

ข้อสุดท้ายที่คนใน DS ควรฟัง สถานการณ์นี้เกิดจริงกับข้อมูล เมื่อคุณสร้าง feature ใหม่ที่เป็นฟังก์ชันของ feature เดิม บางครั้งได้คอลัมน์ที่ดูเหมือนมีข้อมูลใหม่ แต่จริง ๆ ยุบกลับเป็นคอลัมน์เดิม อนุพันธ์ย่อยที่เป็นศูนย์ตลอดคือหน้าตาเชิงคณิตศาสตร์ของสถานการณ์นั้น

## 2.5 หลักการ — อนุพันธ์ย่อยอันดับสูงและแบบผสม

$f_x$ และ $f_y$ ที่ได้ออกมาไม่ใช่ตัวเลข มันเป็น **ฟังก์ชันสองตัวแปรอีกฟังก์ชันหนึ่ง** ฉะนั้นหาอนุพันธ์ย่อยของมันต่อได้ และเพราะแต่ละตัวหาต่อได้สองทาง อนุพันธ์ย่อยอันดับสองจึงมีสี่ตัว

$$
\begin{aligned}
f_{xx} &= \frac{\partial}{\partial x}\left(\frac{\partial f}{\partial x}\right) = \frac{\partial^2 f}{\partial x^2}
&\qquad
f_{xy} &= \frac{\partial}{\partial y}\left(\frac{\partial f}{\partial x}\right) = \frac{\partial^2 f}{\partial y\, \partial x} \\[6pt]
f_{yy} &= \frac{\partial}{\partial y}\left(\frac{\partial f}{\partial y}\right) = \frac{\partial^2 f}{\partial y^2}
&\qquad
f_{yx} &= \frac{\partial}{\partial x}\left(\frac{\partial f}{\partial y}\right) = \frac{\partial^2 f}{\partial x\, \partial y}
\end{aligned}
$$

**กฎการอ่านลำดับ** สัญลักษณ์ห้วน $f_{xy}$ อ่านจาก **ซ้ายไปขวา** คือทำ $x$ ก่อนแล้วทำ $y$ ทีหลัง ส่วนสัญลักษณ์เต็ม $\dfrac{\partial^2 f}{\partial y\, \partial x}$ อ่านจาก **ขวาไปซ้าย** คือทำ $x$ ก่อน (ตัวที่อยู่ติดกับ $f$ มากที่สุด) สองสัญลักษณ์นี้หมายถึงสิ่งเดียวกัน แม้ลำดับตัวอักษรจะกลับกัน วิธีจำที่ไม่พลาดคือ **ใช้สัญลักษณ์ห้วน $f_{xy}$ เป็นหลัก และอ่านซ้ายไปขวาเสมอ**

สองตัวกลาง $f_{xy}$ และ $f_{yx}$ เรียกว่า **อนุพันธ์ย่อยผสม (mixed partial derivatives)** และมีข้อเท็จจริงสำคัญข้อนี้

> **ข้อเท็จจริง** สำหรับฟังก์ชันทุกฟังก์ชันที่เราจะพบในคอร์สนี้ (พหุนาม เศษส่วนพหุนาม เลขชี้กำลัง ลอการิทึม และการประกอบกันของสิ่งเหล่านี้)
> $$f_{xy} = f_{yx}$$
> **ลำดับที่หาอนุพันธ์ไม่มีผล**

เราจะไม่พิสูจน์ข้อเท็จจริงนี้และไม่ต้องจำชื่อของมัน สิ่งที่ต้องทำคือ **ใช้มันเป็นเครื่องตรวจงานตัวเอง** ทุกครั้งที่โจทย์ให้หาอนุพันธ์ย่อยผสม ให้หาทั้งสองทางแล้วเทียบกัน ถ้าไม่เท่ากันคือคำนวณผิด ไม่ใช่ข้อเท็จจริงผิด นี่เป็นเครื่องตรวจที่ดีเยี่ยมเพราะเส้นทางการคำนวณสองทางแทบไม่มีอะไรเหมือนกันเลย โอกาสที่จะผิดเหมือนกันทั้งสองทางจึงต่ำมาก

**ความหมายของแต่ละตัว**

- $f_{xx}$ บอกความเว้าของกราฟหน้าตัดในทิศ $x$ เป็นเรื่องเดียวกับ $f''$ ของสัปดาห์ 3 เพียงแต่ตรึง $y$ ไว้ก่อน
- $f_{yy}$ เหมือนกันแต่ในทิศ $y$
- $f_{xy}$ บอกว่า **ความชันในทิศ $x$ เปลี่ยนไปแค่ไหนเมื่อขยับ $y$** พูดอีกอย่างคือมันวัด **ปฏิสัมพันธ์** ระหว่างสองตัวแปร ถ้า $f_{xy} = 0$ ทุกจุด ความชันในทิศ $x$ ไม่สนใจว่า $y$ อยู่ที่ไหน สองตัวแปรทำงานแยกกันสนิท

ตัวเลขทั้งสี่ตัวนี้จะกลับมาพร้อมกันในสัปดาห์ 5 ในรูป $D = f_{xx} f_{yy} - (f_{xy})^2$ ซึ่งใช้จำแนกว่าจุดที่ $\nabla f = (0,0)$ เป็นจุดต่ำสุด จุดสูงสุด หรือจุดอานม้า สัปดาห์นี้เรายังไม่ใช้ $D$ แค่ต้องหาส่วนประกอบของมันให้ได้แม่น ๆ ก่อน

## 2.6 ตัวอย่างที่ 4 — สี่ตัวจากพหุนามเดียว *(ตรงไปตรงมา)*

**โจทย์:** ให้ $f(x,y) = x^3 y^2$ จงหา $f_{xx}(1,2)$, $f_{yy}(1,2)$, $f_{xy}(1,2)$ และ $f_{yx}(1,2)$

หาอนุพันธ์อันดับหนึ่งก่อน

$$
\begin{aligned}
f_x &= \frac{\partial}{\partial x}\big(x^3 y^2\big) = y^2 \cdot 3x^2 = 3x^2 y^2 && \text{ตรึง } y \text{ ไว้ } y^2 \text{ เป็นสัมประสิทธิ์} \\
f_y &= \frac{\partial}{\partial y}\big(x^3 y^2\big) = x^3 \cdot 2y = 2x^3 y && \text{ตรึง } x \text{ ไว้ } x^3 \text{ เป็นสัมประสิทธิ์}
\end{aligned}
$$

ต่อไปอันดับสองทั้งสี่ตัว

$$
\begin{aligned}
f_{xx} &= \frac{\partial}{\partial x}\big(3x^2 y^2\big) = 3y^2 \cdot 2x = 6x y^2 && \text{ทำ } x \text{ ซ้ำที่ } f_x \\
f_{xy} &= \frac{\partial}{\partial y}\big(3x^2 y^2\big) = 3x^2 \cdot 2y = 6x^2 y && \text{ทำ } y \text{ ต่อจาก } f_x \\
f_{yy} &= \frac{\partial}{\partial y}\big(2x^3 y\big) = 2x^3 \cdot 1 = 2x^3 && \text{ทำ } y \text{ ซ้ำที่ } f_y \\
f_{yx} &= \frac{\partial}{\partial x}\big(2x^3 y\big) = 2y \cdot 3x^2 = 6x^2 y && \text{ทำ } x \text{ ต่อจาก } f_y
\end{aligned}
$$

แทน $(1,2)$

$$
\begin{aligned}
f_{xx}(1,2) &= 6(1)(2)^2 = 6 \cdot 4 = 24 \\
f_{xy}(1,2) &= 6(1)^2 (2) = 12 \\
f_{yy}(1,2) &= 2(1)^3 = 2 \\
f_{yx}(1,2) &= 6(1)^2 (2) = 12
\end{aligned}
$$

**ตรวจคำตอบ:** $f_{xy} = 6x^2 y$ และ $f_{yx} = 6x^2 y$ เป็นนิพจน์เดียวกันเป๊ะ ไม่ใช่แค่เท่ากันที่จุด $(1,2)$ ✓ สอดคล้องกับข้อเท็จจริง $f_{xy} = f_{yx}$ · สังเกตว่าเส้นทางการคำนวณสองทางต่างกันจริง ทางหนึ่งเริ่มจาก $3x^2y^2$ อีกทางเริ่มจาก $2x^3y$ แต่มาบรรจบที่คำตอบเดียวกัน

**ตอบ:** $f_{xx}(1,2) = 24$ · $f_{yy}(1,2) = 2$ · $f_{xy}(1,2) = f_{yx}(1,2) = 12$

## 2.7 ตัวอย่างที่ 5 — อันดับสองที่ต้องใช้กฎลูกโซ่ทุกขั้น *(มีชั้นเชิงเพิ่ม)*

ตัวอย่างนี้ยากกว่าตัวก่อนเพราะทุกขั้นของการหาอนุพันธ์ต้องใช้กฎลูกโซ่ ไม่ใช่แค่ power rule และตัวประกอบด้านในที่คูณออกมาไม่ใช่ $1$ ทั้งสองตัวแปร

**โจทย์:** ให้ $f(x,y) = (2x + y)^4$ จงหา $f_{xx}$, $f_{yy}$, $f_{xy}$, $f_{yx}$ แล้วหาค่าทั้งสี่ที่จุด $(1, -1)$

หาอนุพันธ์อันดับหนึ่ง ให้ $u = 2x+y$ สังเกตว่า $\dfrac{\partial u}{\partial x} = 2$ และ $\dfrac{\partial u}{\partial y} = 1$

$$
\begin{aligned}
f_x &= 4(2x+y)^3 \cdot \frac{\partial}{\partial x}(2x+y) = 4(2x+y)^3 \cdot 2 = 8(2x+y)^3 && \text{ตรึง } y \\
f_y &= 4(2x+y)^3 \cdot \frac{\partial}{\partial y}(2x+y) = 4(2x+y)^3 \cdot 1 = 4(2x+y)^3 && \text{ตรึง } x
\end{aligned}
$$

อันดับสองทั้งสี่ตัว ใช้กฎลูกโซ่อีกครั้งทุกตัว

$$
\begin{aligned}
f_{xx} &= \frac{\partial}{\partial x}\big[8(2x+y)^3\big] = 8 \cdot 3(2x+y)^2 \cdot 2 = 48(2x+y)^2 \\
f_{xy} &= \frac{\partial}{\partial y}\big[8(2x+y)^3\big] = 8 \cdot 3(2x+y)^2 \cdot 1 = 24(2x+y)^2 \\
f_{yy} &= \frac{\partial}{\partial y}\big[4(2x+y)^3\big] = 4 \cdot 3(2x+y)^2 \cdot 1 = 12(2x+y)^2 \\
f_{yx} &= \frac{\partial}{\partial x}\big[4(2x+y)^3\big] = 4 \cdot 3(2x+y)^2 \cdot 2 = 24(2x+y)^2
\end{aligned}
$$

แทนจุด $(1,-1)$ คำนวณค่าในวงเล็บก่อนเสมอ

$$
\begin{aligned}
2x + y &= 2(1) + (-1) = 1 && \text{ค่าในวงเล็บที่จุดนี้} \\
f_{xx}(1,-1) &= 48(1)^2 = 48 \\
f_{xy}(1,-1) &= 24(1)^2 = 24 \\
f_{yy}(1,-1) &= 12(1)^2 = 12 \\
f_{yx}(1,-1) &= 24(1)^2 = 24
\end{aligned}
$$

**ตรวจคำตอบ:** $f_{xy}$ และ $f_{yx}$ ได้ $24(2x+y)^2$ เท่ากันทั้งคู่ ✓ · ตรวจเพิ่มด้วยวิธีตรึงก่อน ตรึง $y = -1$ ได้ $g(x) = (2x-1)^4$ ดังนั้น $g'(x) = 8(2x-1)^3$ และ $g''(x) = 48(2x-1)^2$ ที่ $x = 1$ ได้ $g''(1) = 48(1)^2 = 48$ ✓ ตรงกับ $f_{xx}(1,-1)$

**ตอบ:** $f_{xx}(1,-1) = 48$ · $f_{yy}(1,-1) = 12$ · $f_{xy}(1,-1) = f_{yx}(1,-1) = 24$

**สิ่งที่ต้องระวังที่สุด:** ตัวประกอบ $2$ ที่มาจาก $\partial u/\partial x$ ต้องคูณ **ทุกครั้ง** ที่หาอนุพันธ์เทียบ $x$ ฉะนั้น $f_{xx}$ ได้เลข 2 มาสองครั้ง ($4 \cdot 3 \cdot 2 \cdot 2 = 48$) แต่ $f_{xy}$ ได้มาครั้งเดียว ($4 \cdot 3 \cdot 2 \cdot 1 = 24$) และ $f_{yy}$ ไม่ได้เลย ($4 \cdot 3 \cdot 1 \cdot 1 = 12$) นี่คือที่มาของตัวเลข 48, 24, 12 ที่ลดหลั่นกันทีละสองเท่า

## 2.8 ตัวอย่างที่ 6 — สองเส้นทางที่หน้าตาไม่เหมือนกันเลย แต่บรรจบกันที่ศูนย์ *(ผลลัพธ์ผิดคาด — มีแต่ใน note)*

**โจทย์:** ให้ $f(x,y) = x^2 y + \ln(x + 2y)$ จงหา $f_{xy}$ และ $f_{yx}$ ทั้งสองทาง แล้วหาค่าที่จุด $(1, 0)$

**เส้นทางที่ 1** ทำ $x$ ก่อนแล้ว $y$

$$
\begin{aligned}
f_x &= \frac{\partial}{\partial x}\big(x^2 y\big) + \frac{\partial}{\partial x}\ln(x+2y) && \text{ตรึง } y \\
&= 2xy + \frac{1}{x+2y} \cdot \frac{\partial}{\partial x}(x+2y) && \text{กฎลูกโซ่กับ } \ln \\
&= 2xy + \frac{1}{x+2y} \cdot 1 = 2xy + (x+2y)^{-1} && \\[6pt]
f_{xy} &= \frac{\partial}{\partial y}\Big[2xy + (x+2y)^{-1}\Big] && \text{ตรึง } x \text{ คราวนี้} \\
&= 2x + (-1)(x+2y)^{-2} \cdot \frac{\partial}{\partial y}(x+2y) && \text{กฎลูกโซ่} \\
&= 2x - (x+2y)^{-2} \cdot 2 && \frac{\partial}{\partial y}(x+2y) = 2 \\
&= 2x - \frac{2}{(x+2y)^2} &&
\end{aligned}
$$

**เส้นทางที่ 2** ทำ $y$ ก่อนแล้ว $x$

$$
\begin{aligned}
f_y &= \frac{\partial}{\partial y}\big(x^2 y\big) + \frac{\partial}{\partial y}\ln(x+2y) && \text{ตรึง } x \\
&= x^2 + \frac{1}{x+2y} \cdot 2 = x^2 + \frac{2}{x+2y} && \text{กฎลูกโซ่ ตัวประกอบด้านในคือ } 2 \\[6pt]
f_{yx} &= \frac{\partial}{\partial x}\Big[x^2 + 2(x+2y)^{-1}\Big] && \text{ตรึง } y \text{ คราวนี้} \\
&= 2x + 2 \cdot (-1)(x+2y)^{-2} \cdot 1 && \text{กฎลูกโซ่ ตัวประกอบด้านในคือ } 1 \\
&= 2x - \frac{2}{(x+2y)^2} &&
\end{aligned}
$$

เทียบสองผลลัพธ์ ได้ $2x - \dfrac{2}{(x+2y)^2}$ เหมือนกันเป๊ะ ✓

หาค่าที่จุด $(1,0)$

$$
\begin{aligned}
x + 2y &= 1 + 2(0) = 1 && \text{ค่าในวงเล็บ ต้องไม่เป็นศูนย์ และ } \ln \text{ ต้องรับค่าบวก} \\
f_{xy}(1,0) &= 2(1) - \frac{2}{1^2} = 2 - 2 = 0 &&
\end{aligned}
$$

**ตรวจคำตอบ:** สังเกตว่า $f_x = 2xy + (x+2y)^{-1}$ กับ $f_y = x^2 + 2(x+2y)^{-1}$ หน้าตาไม่เหมือนกันเลย พจน์แรกของตัวหนึ่งมี $y$ อีกตัวไม่มี พจน์ที่สองต่างกันด้วยตัวประกอบ 2 ทั้งที่จุดตั้งต้นเป็นฟังก์ชันเดียวกัน แต่การหาอนุพันธ์ต่ออีกทีทำให้สองเส้นทางบรรจบกันพอดี · ตรวจเชิงตัวเลขอีกชั้น ที่จุด $(1,0)$ พจน์ $2x$ ให้ $2$ และพจน์ $-2/(x+2y)^2$ ให้ $-2$ สองพจน์หักกันหมดจริง ✓ · ตรวจโดเมนด้วย ที่จุด $(1,0)$ ค่า $x+2y = 1 > 0$ อยู่ในโดเมนของ $\ln$ ✓

**สิ่งที่เกิดขึ้น:** ผลลัพธ์ผิดคาดสองชั้น

ชั้นแรก **สองเส้นทางที่หน้าตากลางทางไม่เหมือนกันเลย ให้ผลปลายทางเท่ากันเป๊ะ** ตัวประกอบด้านในของกฎลูกโซ่คือ $1$ ในเส้นทางหนึ่งและ $2$ ในอีกเส้นทาง แต่สุดท้ายทั้งสองทางได้เลข $2$ คูณเข้ามาที่พจน์ $\ln$ พอดี เพียงแต่ได้มาในขั้นที่ต่างกัน นี่คือเหตุผลที่การเทียบ $f_{xy}$ กับ $f_{yx}$ เป็นเครื่องตรวจที่แข็งแรง

ชั้นสอง **$f_{xy}(1,0) = 0$ แต่ไม่ได้แปลว่าสองตัวแปรไม่มีปฏิสัมพันธ์กัน** ถ้าไปดูจุดอื่น เช่น $(1, 1)$ จะได้ $x+2y = 3$ และ $f_{xy}(1,1) = 2 - \frac{2}{9} = \frac{16}{9} \ne 0$ ฉะนั้นค่าศูนย์ที่จุด $(1,0)$ เป็นเรื่องเฉพาะจุดนั้น เกิดจากพจน์ปฏิสัมพันธ์สองพจน์ที่มีเครื่องหมายตรงข้ามหักกันพอดี ไม่ใช่คุณสมบัติของฟังก์ชันทั้งฟังก์ชัน **การสรุปคุณสมบัติทั่วไปจากค่าที่จุดเดียวเป็นความผิดพลาดที่อันตราย** และเป็นความผิดพลาดที่จะกลับมาเจออีกในสัปดาห์ 5

**ตอบ:** $f_{xy} = f_{yx} = 2x - \dfrac{2}{(x+2y)^2}$ · ค่าที่จุด $(1,0)$ เท่ากับ $0$

## 2.9 หาเกรเดียนต์ของ $L(w,b)$ ให้ครบ — แล้วหยุด

ตอนนี้เรามีเครื่องมือพอที่จะทำสิ่งที่สำคัญที่สุดของสัปดาห์นี้แล้ว

**โจทย์:** ให้ $L(w, b) = \displaystyle\sum_{i=1}^{n} \big(y_i - w x_i - b\big)^2$ โดย $(x_i, y_i)$ เป็นข้อมูลที่ให้มา จงหา $\dfrac{\partial L}{\partial w}$ และ $\dfrac{\partial L}{\partial b}$

**หา $\dfrac{\partial L}{\partial w}$ ตรึง $b$ ไว้ ถือ $b$ เป็นค่าคงตัว และข้อมูล $x_i, y_i$ เป็นค่าคงตัวอยู่แล้ว**

ให้ $r_i = y_i - w x_i - b$ เรียกว่า **residual** ของจุดที่ $i$ พจน์ที่ $i$ ของผลรวมคือ $r_i^2$ ใช้กฎลูกโซ่

$$
\begin{aligned}
\frac{\partial}{\partial w}\big(r_i^2\big) &= 2 r_i \cdot \frac{\partial r_i}{\partial w} && \text{กฎลูกโซ่ (สัปดาห์ 3)} \\
\frac{\partial r_i}{\partial w} &= \frac{\partial}{\partial w}\big(y_i - w x_i - b\big) = 0 - x_i - 0 = -x_i && y_i,\, x_i,\, b \text{ เป็นค่าคงตัว} \\
\frac{\partial}{\partial w}\big(r_i^2\big) &= 2 r_i \cdot (-x_i) = -2 x_i r_i && \\[6pt]
\frac{\partial L}{\partial w} &= \sum_{i=1}^{n} \big(-2 x_i r_i\big) = -2 \sum_{i=1}^{n} x_i \big(y_i - w x_i - b\big) && \text{อนุพันธ์ของผลรวมคือผลรวมของอนุพันธ์}
\end{aligned}
$$

**หา $\dfrac{\partial L}{\partial b}$ ตรึง $w$ ไว้**

$$
\begin{aligned}
\frac{\partial r_i}{\partial b} &= \frac{\partial}{\partial b}\big(y_i - w x_i - b\big) = 0 - 0 - 1 = -1 && \\
\frac{\partial}{\partial b}\big(r_i^2\big) &= 2 r_i \cdot (-1) = -2 r_i && \text{กฎลูกโซ่} \\[6pt]
\frac{\partial L}{\partial b} &= -2 \sum_{i=1}^{n} \big(y_i - w x_i - b\big) &&
\end{aligned}
$$

ดังนั้น

$$
\nabla L(w,b) \;=\; \left(\frac{\partial L}{\partial w},\; \frac{\partial L}{\partial b}\right) \;=\; \left(-2 \sum_{i=1}^{n} x_i\big(y_i - wx_i - b\big),\;\; -2\sum_{i=1}^{n} \big(y_i - wx_i - b\big)\right)
$$

**ตรวจคำตอบด้วยข้อมูลสามจุดจากหัวข้อ 1.5** ข้อมูลคือ $(1,2), (2,3), (3,5)$ ทดสอบที่ $(w,b) = (1,1)$ หา residual ก่อน

$$
\begin{aligned}
r_1 &= 2 - 1(1) - 1 = 0 \\
r_2 &= 3 - 1(2) - 1 = 0 \\
r_3 &= 5 - 1(3) - 1 = 1
\end{aligned}
$$

แทนในสูตร

$$
\begin{aligned}
\frac{\partial L}{\partial w}\Big|_{(1,1)} &= -2\big[1(0) + 2(0) + 3(1)\big] = -2(3) = -6 \\
\frac{\partial L}{\partial b}\Big|_{(1,1)} &= -2\big[0 + 0 + 1\big] = -2
\end{aligned}
$$

ตรวจอีกทางด้วยรูปกระจายจากหัวข้อ 1.5 ซึ่งคือ $L = 14w^2 + 3b^2 + 12wb - 46w - 20b + 38$

$$
\begin{aligned}
\frac{\partial L}{\partial w} &= 28w + 12b - 46 && \text{ตรึง } b \\
\frac{\partial L}{\partial b} &= 6b + 12w - 20 && \text{ตรึง } w \\[4pt]
\frac{\partial L}{\partial w}\Big|_{(1,1)} &= 28 + 12 - 46 = -6 && ✓ \\
\frac{\partial L}{\partial b}\Big|_{(1,1)} &= 6 + 12 - 20 = -2 && ✓
\end{aligned}
$$

สองวิธีให้คำตอบเดียวกัน ✓ ดังนั้น $\nabla L(1,1) = (-6, -2)$

ทดสอบอีกจุดหนึ่งเพื่อความมั่นใจ ที่ $(w,b) = (2,0)$ ได้ $r_1 = 2-2-0 = 0$, $r_2 = 3-4-0 = -1$, $r_3 = 5-6-0 = -1$

$$
\begin{aligned}
\frac{\partial L}{\partial w}\Big|_{(2,0)} &= -2\big[1(0) + 2(-1) + 3(-1)\big] = -2(-5) = 10 \\
\frac{\partial L}{\partial b}\Big|_{(2,0)} &= -2\big[0 - 1 - 1\big] = -2(-2) = 4
\end{aligned}
$$

ตรวจด้วยรูปกระจาย $28(2) + 12(0) - 46 = 56 - 46 = 10$ ✓ และ $6(0) + 12(2) - 20 = 24 - 20 = 4$ ✓ ดังนั้น $\nabla L(2,0) = (10, 4)$

### หยุดที่นี่

สังเกตสิ่งที่อยู่ตรงหน้า $\dfrac{\partial L}{\partial w} = 28w + 12b - 46$ และ $\dfrac{\partial L}{\partial b} = 12w + 6b - 20$ ทั้งสองนิพจน์เป็น **เชิงเส้น** ใน $w$ และ $b$ ไม่มีกำลังสอง ไม่มีรากที่สอง ไม่มีอะไรน่ากลัวเลย

ก้าวต่อไปที่ทุกคนเดาได้คือ ให้ทั้งสองเท่ากับศูนย์ แล้วเราจะได้ **ระบบสมการเชิงเส้น 2 ตัวแปร 2 สมการ** ซึ่งเป็นสิ่งที่เราแก้เป็นแล้วตั้งแต่สัปดาห์ 2

**แต่สัปดาห์นี้เราจะหยุดที่นี่**

**สัปดาห์หน้าเราจะให้มันเท่ากับศูนย์แล้วแก้** และเมื่อทำกับข้อมูล $n$ จุดแบบทั่วไป ผลลัพธ์ที่ออกมาคือสูตรที่ใช้ทำงานจริงในโลกทั้งใบ นั่นคือ Capstone 50 นาทีของสัปดาห์ 5 และเป็นเหตุผลที่คอร์สนี้มีอยู่

งานของคุณสัปดาห์นี้ไม่ใช่การหาคำตอบ **งานของคุณคือหาอนุพันธ์ย่อยให้แม่นจนไม่มีทางผิด** เพราะถ้าบรรทัด $\partial r_i / \partial w = -x_i$ ผิด ทุกอย่างที่สร้างต่อจากมันในสัปดาห์หน้าก็ผิดหมด

| ที่พลาด | ทำไมพลาด | วิธีกัน |
|---|---|---|
| หา $f_x$ ของ $x^2 y^3$ ได้ $2x \cdot 3y^2$ | เผลอหาอนุพันธ์ทั้งสองตัวแปรพร้อมกัน | เขียนบรรทัด "ตรึง $y$" ก่อนลงมือทุกครั้ง แล้วมองว่า $y^3$ คือเลข 8 · อนุพันธ์ของ $8x^2$ ไม่มีทางมี 8 หายไป |
| หา $\frac{\partial}{\partial x}(xy)$ ได้ $1$ หรือ $0$ | เห็น $xy$ เป็นก้อนเดียวแล้วสับสน | **เขียนใหม่เป็น $y \cdot x$ ก่อน** จะเห็นว่าเป็นค่าคงตัวคูณ $x$ อนุพันธ์คือ $y$ |
| ลืมตัวประกอบด้านในของกฎลูกโซ่ เช่น $\frac{\partial}{\partial x}(2x+y)^3 = 3(2x+y)^2$ | ทำเหมือนหนึ่งตัวแปรที่ตัวประกอบด้านในเป็น 1 | ตัวประกอบด้านในของ $2x+y$ คือ $2$ เทียบ $x$ และ $1$ เทียบ $y$ **เขียน $\partial u/\partial x$ ออกมาเป็นบรรทัดแยก** |
| อ่าน $f_{xy}$ ว่าทำ $y$ ก่อน | สับสนกับสัญลักษณ์เต็ม $\partial^2 f / \partial y\,\partial x$ ที่อ่านขวาไปซ้าย | ใช้สัญลักษณ์ห้วนเป็นหลัก **$f_{xy}$ อ่านซ้ายไปขวา ทำ $x$ ก่อน** และเพราะ $f_{xy}=f_{yx}$ ความผิดพลาดนี้ไม่ทำให้คำตอบผิด แต่ทำให้สื่อสารผิด |
| เห็น $f_{xy} = f_{yx}$ แล้วเลิกตรวจ | คิดว่าถ้ายังไงก็เท่ากัน หาทางเดียวก็พอ | ข้อเท็จจริงบอกว่า **คำตอบที่ถูก** ทั้งสองทางเท่ากัน ไม่ได้รับประกันว่าคำตอบของคุณถูก **หาสองทางแล้วเทียบ คือเครื่องตรวจฟรีที่แข็งแรงที่สุดในสัปดาห์นี้** |
| หา $\partial L/\partial w$ แล้วลืมเครื่องหมายลบจาก $-x_i$ | ใช้กฎลูกโซ่แล้วข้ามบรรทัด $\partial r_i/\partial w$ | เขียน $r_i = y_i - wx_i - b$ ออกมาก่อน แล้วหา $\partial r_i/\partial w$ เป็นบรรทัดของตัวเอง จะเห็นเครื่องหมายลบชัด |
| นึกว่าตัวแปรของ $L$ คือ $x$ กับ $y$ | ชื่อตัวแปรคุ้นเกินไป | $x_i$ และ $y_i$ คือ **ข้อมูล** ซึ่งเป็นค่าคงตัว · ตัวแปรคือ **พารามิเตอร์** $w$ กับ $b$ · ถ้าสับสน แทนข้อมูลเป็นตัวเลขลงไปให้หมดก่อน |
| ถือว่า $f_{xy}(P) = 0$ แล้วสรุปว่า $f_{xy} = 0$ ทุกจุด | เอาค่าที่จุดเดียวไปสรุปทั้งฟังก์ชัน | ค่าที่จุดกับนิพจน์เป็นของต่างชนิดกัน ดูตัวอย่าง 2.8 ที่ $f_{xy}(1,0)=0$ แต่ $f_{xy}(1,1) = 16/9$ |

## 2.11 ใช้ทำอะไรใน DS/CS

อนุพันธ์ย่อยคือคำตอบของคำถามที่คนทำงานกับโมเดลถามทุกวันว่า **"ถ้าฉันขยับพารามิเตอร์ตัวนี้ขึ้นทีละน้อย ความเลวจะเปลี่ยนไปทางไหนและแรงแค่ไหน"** ค่าที่ตอบคำถามนี้คือ $\partial L / \partial w$ ตรง ๆ เครื่องหมายของมันบอกทิศ ถ้าเป็นลบ แปลว่าเพิ่ม $w$ แล้ว $L$ จะลด และขนาดของมันบอกความไว

ยกตัวอย่างจากตัวเลขที่เราคำนวณมาเอง ที่ $(w,b) = (1,1)$ เราได้ $\nabla L = (-6, -2)$ อ่านได้ว่า ทั้งสองพารามิเตอร์ถ้าเพิ่มขึ้นจะทำให้ $L$ ลดลง แต่ $w$ ไวกว่า $b$ สามเท่า ฉะนั้นถ้าเวลามีจำกัดและปรับได้ตัวเดียว ให้ปรับ $w$ นี่เป็นการตัดสินใจเชิงวิศวกรรมที่อ่านออกจากคู่อันดับสองตัวเลข

อนุพันธ์ย่อยผสม $f_{xy}$ มีบทบาทที่ต่างออกไปแต่สำคัญไม่แพ้กัน มันตอบคำถามว่า **พารามิเตอร์สองตัวนี้ต้องปรับพร้อมกันหรือปรับแยกกันได้** ถ้า $L_{wb} = 0$ ทุกจุด ผลของการปรับ $w$ ไม่ขึ้นกับว่า $b$ อยู่ที่ไหน ปรับแยกกันได้เลย แต่ถ้า $L_{wb} \ne 0$ อย่างในตัวอย่าง $L$ ของเราซึ่ง $L_{wb} = 12$ การปรับ $w$ ทีละตัวจนพอใจ แล้วค่อยปรับ $b$ ทีละตัวจนพอใจ **จะไม่ให้คำตอบที่ดีที่สุด** เพราะพอปรับ $b$ เสร็จ ค่า $w$ ที่เคยดีที่สุดก็ไม่ดีที่สุดอีกแล้ว นี่คือเหตุผลเชิงคณิตศาสตร์ที่การจูนพารามิเตอร์ทีละตัว (one-factor-at-a-time) เป็นวิธีที่ให้ผลไม่ดีในทางปฏิบัติ และเป็นเหตุผลที่เราต้องแก้ **ระบบสมการ** ไม่ใช่แก้สมการเดี่ยวสองครั้ง

สุดท้าย ค่าอนุพันธ์ย่อยที่เป็นศูนย์ตลอด (ตัวอย่าง 2.4) มีคู่แฝดในงานจริงคือ feature ที่ไม่มีผลต่อผลลัพธ์เลย ถ้าอนุพันธ์ย่อยของ loss เทียบน้ำหนักของ feature หนึ่งเป็นศูนย์ตลอดทุกค่าพารามิเตอร์ นั่นเป็นสัญญาณว่า feature นั้นไม่ได้ให้ข้อมูลอะไร หรือซ้ำซ้อนกับ feature อื่นแบบสมบูรณ์

# 3. เกรเดียนต์ $\nabla f$

*(ตรงกับแถวที่ 3 ในตาราง 180 นาที — Lecture 40 นาที)*

## 3.1 หลักการ

เรามีตัวเลขสองตัวคือ $f_x$ กับ $f_y$ ที่จุดหนึ่ง สิ่งที่จะทำต่อไปดูเหมือนเป็นการจัดระเบียบสัญลักษณ์เฉย ๆ แต่จริง ๆ เป็นการเปลี่ยนมุมมองที่ทำให้เรขาคณิตทั้งหมดโผล่ออกมา นั่นคือ **เอาสองตัวเลขนั้นมามัดเป็นเวกเตอร์เดียว**

**นิยาม** เกรเดียนต์ของ $f$ ที่จุด $(a,b)$ คือเวกเตอร์

$$
\nabla f(a,b) \;=\; \big(f_x(a,b),\; f_y(a,b)\big)
$$

สัญลักษณ์ $\nabla$ อ่านว่า "เดล" หรือ "แนบลา" · ข้อควรจำสองข้อเรื่องชนิดของวัตถุ

- $f(a,b)$ เป็น **จำนวน** — ความสูงของผิวที่จุดนั้น
- $\nabla f(a,b)$ เป็น **เวกเตอร์ในระนาบ** — ไม่ใช่จำนวน และไม่ใช่เวกเตอร์สามมิติ มันเป็นลูกศรที่วาดบนแผนที่ contour ได้เลย

**ความหมายเชิงเรขาคณิตข้อที่ 1 — ทิศที่ฟังก์ชันเพิ่มชันที่สุด**

จากจุด $(a,b)$ มีทิศให้เดินรอบตัว 360 องศา แต่ละทิศทำให้ค่า $f$ เปลี่ยนด้วยอัตราต่างกัน ข้อเท็จจริงคือ

> ทิศที่ทำให้ $f$ **เพิ่มขึ้นเร็วที่สุด** คือทิศของ $\nabla f(a,b)$
> ทิศที่ทำให้ $f$ **ลดลงเร็วที่สุด** คือทิศของ $-\nabla f(a,b)$
> และ **ความยาว** $\|\nabla f(a,b)\| = \sqrt{f_x^2 + f_y^2}$ คืออัตราการเพิ่มในทิศที่ชันที่สุดนั้น

พูดเป็นภาษาภูมิประเทศ ถ้าคุณยืนอยู่บนเนินและอยากขึ้นให้เร็วที่สุด ให้เดินตาม $\nabla f$ ถ้าอยากลงให้เร็วที่สุด ให้เดินตาม $-\nabla f$ · ความยาวของลูกศรบอกว่าเนินตรงนั้นชันแค่ไหน ที่บริเวณแบนลูกศรจะสั้น ที่หน้าผาลูกศรจะยาว

**ความหมายเชิงเรขาคณิตข้อที่ 2 — ตั้งฉากกับ level curve**

> $\nabla f(a,b)$ **ตั้งฉากกับ level curve ที่ผ่านจุด $(a,b)$**

ข้อนี้ฟังดูเป็นข้อเท็จจริงเพิ่มเติม แต่จริง ๆ มันเป็นผลที่ตามมาจากข้อแรกอย่างหลีกเลี่ยงไม่ได้ เหตุผลอ่านง่ายมาก **เดินไปตาม level curve คือเดินไปโดยที่ค่า $f$ ไม่เปลี่ยนเลย** ฉะนั้นทิศตามแนว level curve คือทิศที่อัตราการเปลี่ยนเป็นศูนย์ ซึ่งเป็นทิศที่ "ไม่ชันเลย" และทิศที่ชันที่สุดต้องเป็นทิศที่ห่างจากทิศไม่ชันที่สุดเท่าที่จะเป็นไปได้ นั่นคือตั้งฉาก

ข้อนี้ทำให้เราตรวจงานตัวเองได้ด้วยมือ **ถ้าคำนวณ $\nabla f$ ที่จุดหนึ่งได้ และหาความชันของเส้นสัมผัส level curve ที่จุดเดียวกันได้ ผลคูณของความชันสองอันต้องเป็น $-1$** เราจะใช้เครื่องตรวจนี้ในทุกตัวอย่างของหัวข้อนี้

วิธีหาความชันเส้นสัมผัส level curve ด้วยมือ ใช้การหาอนุพันธ์แบบให้ $y$ เป็นฟังก์ชันของ $x$ บนสมการ $f(x,y) = c$ แล้วแก้หา $y'$

## 3.2 ตัวอย่างที่ 1 — เกรเดียนต์บนวงรี พร้อมตรวจการตั้งฉาก *(ตรงไปตรงมา)*

**โจทย์:** ให้ $f(x,y) = x^2 + 3y^2$ จงหา $\nabla f(2,1)$ · หา level curve ที่ผ่านจุดนั้น · แล้วตรวจว่าเกรเดียนต์ตั้งฉากกับเส้นสัมผัสจริง

หาเกรเดียนต์

$$
\begin{aligned}
f_x &= \frac{\partial}{\partial x}\big(x^2 + 3y^2\big) = 2x + 0 = 2x && \text{ตรึง } y \\
f_y &= \frac{\partial}{\partial y}\big(x^2 + 3y^2\big) = 0 + 6y = 6y && \text{ตรึง } x \\[4pt]
\nabla f(2,1) &= \big(2(2),\; 6(1)\big) = (4, 6) &&
\end{aligned}
$$

หา level curve ที่ผ่าน $(2,1)$

$$
c = f(2,1) = 2^2 + 3(1)^2 = 4 + 3 = 7 \qquad\Rightarrow\qquad x^2 + 3y^2 = 7
$$

หาความชันเส้นสัมผัสของ level curve ที่จุดนั้น ถือ $y$ เป็นฟังก์ชันของ $x$ บนเส้น $x^2 + 3y^2 = 7$

$$
\begin{aligned}
\frac{d}{dx}\big(x^2 + 3y^2\big) &= \frac{d}{dx}(7) && \text{หาอนุพันธ์ทั้งสองข้างเทียบ } x \\
2x + 6y \cdot \frac{dy}{dx} &= 0 && \text{กฎลูกโซ่ที่พจน์ } 3y^2 \\
\frac{dy}{dx} &= -\frac{2x}{6y} = -\frac{x}{3y} && \text{แก้หา } dy/dx \\
\frac{dy}{dx}\Big|_{(2,1)} &= -\frac{2}{3(1)} = -\frac{2}{3} && \text{ความชันเส้นสัมผัส}
\end{aligned}
$$

**ตรวจคำตอบ — การตั้งฉาก** เกรเดียนต์ $(4,6)$ เป็นลูกศรที่ไปทางขวา 4 และขึ้น 6 ความชันของมันคือ

$$
\text{ความชันของ } \nabla f = \frac{6}{4} = \frac{3}{2}
\qquad\Rightarrow\qquad
\frac{3}{2} \times \left(-\frac{2}{3}\right) = -1 \quad ✓
$$

ผลคูณเป็น $-1$ พอดี ตั้งฉากจริง ✓

**ตรวจคำตอบ — จุดอยู่บนเส้นจริง** แทน $(2,1)$ ใน $x^2+3y^2 = 7$ ได้ $4 + 3 = 7$ ✓

**ความยาวของเกรเดียนต์**

$$
\|\nabla f(2,1)\| = \sqrt{4^2 + 6^2} = \sqrt{16+36} = \sqrt{52} = 2\sqrt{13}
$$

**ตอบ:** $\nabla f(2,1) = (4,6)$ · level curve คือวงรี $x^2 + 3y^2 = 7$ · ผลคูณความชันเท่ากับ $-1$ จึงตั้งฉาก · ความยาวเกรเดียนต์เท่ากับ $2\sqrt{13}$

**อ่านผลเป็นภาษาคน:** ที่จุด $(2,1)$ ทิศที่ค่าฟังก์ชันพุ่งขึ้นเร็วที่สุดคือทิศ $(4,6)$ ซึ่งเอียงขึ้นชันกว่า 45 องศา เพราะช่อง $y$ มากกว่าช่อง $x$ ซึ่งสอดคล้องกับตัวอย่าง 1.3 ที่บอกว่าผิวแบบนี้ชันในทิศ $y$ มากกว่า

## 3.3 ตัวอย่างที่ 2 — เกรเดียนต์ที่ต้องใช้กฎลูกโซ่ และความยาวออกมาเป็น 1 *(มีชั้นเชิงเพิ่ม)*

ตัวอย่างนี้มีชั้นเชิงเพิ่มสองอย่าง หนึ่งคือต้องใช้กฎลูกโซ่กับรากที่สอง สองคือผลลัพธ์เป็นเศษส่วนที่จัดรูปแล้วสวยผิดคาด

**โจทย์:** ให้ $f(x,y) = \sqrt{x^2 + y^2}$ จงหา $\nabla f(3,4)$ และ $\|\nabla f(3,4)\|$ แล้วตรวจการตั้งฉากกับ level curve

เขียนใหม่เป็นเลขยกกำลังเศษส่วนก่อนจะง่ายขึ้น $f = (x^2+y^2)^{1/2}$

$$
\begin{aligned}
f_x &= \frac{1}{2}\big(x^2+y^2\big)^{-1/2} \cdot \frac{\partial}{\partial x}\big(x^2+y^2\big) && \text{กฎลูกโซ่ ตรึง } y \\
&= \frac{1}{2}\big(x^2+y^2\big)^{-1/2} \cdot 2x && \frac{\partial}{\partial x}(x^2+y^2) = 2x \\
&= \frac{x}{\sqrt{x^2+y^2}} && \text{ตัด } 2 \\[6pt]
f_y &= \frac{1}{2}\big(x^2+y^2\big)^{-1/2} \cdot 2y = \frac{y}{\sqrt{x^2+y^2}} && \text{ทำแบบเดียวกัน ตรึง } x
\end{aligned}
$$

แทนจุด $(3,4)$ คำนวณตัวส่วนก่อน

$$
\begin{aligned}
\sqrt{3^2+4^2} &= \sqrt{9+16} = \sqrt{25} = 5 && \\
\nabla f(3,4) &= \left(\frac{3}{5},\; \frac{4}{5}\right) &&
\end{aligned}
$$

หาความยาว

$$
\|\nabla f(3,4)\| = \sqrt{\left(\tfrac{3}{5}\right)^2 + \left(\tfrac{4}{5}\right)^2} = \sqrt{\frac{9}{25} + \frac{16}{25}} = \sqrt{\frac{25}{25}} = \sqrt{1} = 1
$$

หา level curve และตรวจการตั้งฉาก

$$
\begin{aligned}
c &= f(3,4) = 5 && \Rightarrow\; \sqrt{x^2+y^2} = 5 \;\Leftrightarrow\; x^2+y^2 = 25 \\
2x + 2y \frac{dy}{dx} &= 0 && \text{หาอนุพันธ์ทั้งสองข้างของ } x^2+y^2=25 \\
\frac{dy}{dx} &= -\frac{x}{y} = -\frac{3}{4} && \text{แทน } (3,4)
\end{aligned}
$$

**ตรวจคำตอบ — การตั้งฉาก** ความชันของ $\nabla f = \left(\tfrac35, \tfrac45\right)$ คือ $\dfrac{4/5}{3/5} = \dfrac{4}{3}$

$$
\frac{4}{3} \times \left(-\frac{3}{4}\right) = -1 \quad ✓
$$

**ตรวจคำตอบ — จุดอยู่บนเส้นจริง** $3^2 + 4^2 = 25$ ✓

**ตอบ:** $\nabla f(3,4) = \left(\tfrac{3}{5}, \tfrac{4}{5}\right)$ · $\|\nabla f(3,4)\| = 1$ · level curve คือวงกลม $x^2+y^2=25$ · ตั้งฉากจริงเพราะผลคูณความชันเป็น $-1$

**สิ่งที่น่าสนใจ:** ความยาวเกรเดียนต์เท่ากับ $1$ พอดี และถ้าลองจุดอื่น เช่น $(5,0)$ จะได้ $\nabla f = (1,0)$ ซึ่งยาว 1 เหมือนกัน · ที่ $(0,-2)$ จะได้ $\nabla f = (0,-1)$ ยาว 1 อีก ฟังก์ชันนี้คือระยะทางจากจุดกำเนิด และการเดินออกห่างจากจุดกำเนิด 1 หน่วยทำให้ระยะเพิ่มขึ้น 1 หน่วยเสมอ ไม่ว่าจะอยู่ที่ไหน ผิวนี้จึงชันเท่ากันทุกที่ ซึ่งตรงกับที่เกรเดียนต์ยาวเท่ากันทุกจุด · และเกรเดียนต์ชี้ออกจากจุดกำเนิดตามแนวรัศมี ซึ่งตั้งฉากกับวงกลมพอดีตามที่คาด

## 3.4 ตัวอย่างที่ 3 — จุดที่ $\nabla f = (0,0)$ และเรขาคณิตพัง *(ผลลัพธ์ผิดคาด — มีแต่ใน note)*

**โจทย์:** ให้ $f(x,y) = x^2 - y^2$ จงหา $\nabla f(3,1)$ พร้อมตรวจการตั้งฉาก แล้วหา $\nabla f(0,0)$ และอธิบายว่าเกิดอะไรขึ้นกับความหมายเชิงเรขาคณิตทั้งสองข้อที่จุดนั้น

**ส่วนที่ 1 — จุดธรรมดา $(3,1)$**

$$
\begin{aligned}
f_x &= \frac{\partial}{\partial x}\big(x^2-y^2\big) = 2x && \text{ตรึง } y \\
f_y &= \frac{\partial}{\partial y}\big(x^2-y^2\big) = -2y && \text{ตรึง } x \\[4pt]
\nabla f(3,1) &= \big(2(3),\; -2(1)\big) = (6, -2) &&
\end{aligned}
$$

level curve ที่ผ่านจุดนี้

$$
c = f(3,1) = 9 - 1 = 8 \qquad\Rightarrow\qquad x^2 - y^2 = 8
$$

หาความชันเส้นสัมผัส

$$
\begin{aligned}
2x - 2y\frac{dy}{dx} &= 0 && \text{หาอนุพันธ์ทั้งสองข้างเทียบ } x \\
\frac{dy}{dx} &= \frac{x}{y} = \frac{3}{1} = 3 && \text{แทน } (3,1)
\end{aligned}
$$

**ตรวจคำตอบ:** ความชันของ $\nabla f = (6,-2)$ คือ $\dfrac{-2}{6} = -\dfrac{1}{3}$ และ $3 \times \left(-\dfrac13\right) = -1$ ✓ ตั้งฉากจริง · แทน $(3,1)$ ใน $x^2-y^2=8$ ได้ $9-1=8$ ✓

**ส่วนที่ 2 — จุดกำเนิด**

$$
\nabla f(0,0) = \big(2(0),\; -2(0)\big) = (0, 0)
$$

**สิ่งที่เกิดขึ้น:** ที่จุดกำเนิด ความหมายเชิงเรขาคณิตทั้งสองข้อพังพร้อมกัน และพังในทางที่บอกอะไรเราจริง ๆ

พังข้อที่ 1 **"ทิศที่ฟังก์ชันเพิ่มชันที่สุด" ไม่มี** เพราะ $\nabla f(0,0)$ เป็นเวกเตอร์ศูนย์ ซึ่งไม่มีทิศ ความยาวก็เป็น $\sqrt{0+0} = 0$ แปลว่าอัตราการเพิ่มในทิศที่ชันที่สุดคือศูนย์ ผิวแบนราบที่จุดนั้น

พังข้อที่ 2 **"ตั้งฉากกับ level curve" พูดไม่ได้** เพราะ level set ที่ระดับ $c = f(0,0) = 0$ คือ

$$
x^2 - y^2 = 0 \;\Longleftrightarrow\; (x-y)(x+y) = 0 \;\Longleftrightarrow\; y = x \;\text{ หรือ }\; y = -x
$$

ซึ่งเป็นเส้นตรงสองเส้นตัดกันที่จุดกำเนิด เหมือนตัวอย่าง 1.4 ที่เราเจอมาแล้ว ที่จุดตัดไม่มีเส้นสัมผัสเส้นเดียว จึงไม่มีอะไรให้ตั้งฉากด้วย และโชคดีที่เวกเตอร์ศูนย์ก็ไม่มีทิศให้ตั้งฉากอยู่แล้ว ทั้งสองด้านของประโยคหายไปพร้อมกันอย่างสอดคล้องกัน

**ทำไมจุดแบบนี้สำคัญ:** สังเกตว่าผิวนี้ที่จุดกำเนิด **ไม่ใช่จุดต่ำสุดและไม่ใช่จุดสูงสุด** ตรวจได้ด้วยมือ

$$
\begin{aligned}
\text{เดินไปทาง } x \text{ (ตรึง } y=0):\quad & f(t, 0) = t^2 \;\ge 0 && \text{ค่าเพิ่มขึ้นจากศูนย์ — เหมือนก้นหุบเขา} \\
\text{เดินไปทาง } y \text{ (ตรึง } x=0):\quad & f(0, t) = -t^2 \;\le 0 && \text{ค่าลดลงจากศูนย์ — เหมือนยอดสัน}
\end{aligned}
$$

จุดเดียวกันเป็นก้นหุบเขาถ้ามองในทิศหนึ่ง และเป็นยอดสันถ้ามองในทิศตั้งฉาก รูปทรงแบบนี้คือ **จุดอานม้า (saddle point)** และมันเป็นเหตุผลที่ประโยค "$\nabla f = (0,0)$ แปลว่าเจอจุดต่ำสุด" **ผิด**

[FIGURE | A | w04_f05_zero_gradient_crossing_levelset | ภาพสองช่องซ้ายขวา ช่องซ้ายวาดไฮเพอร์โบลาของ x²−y²=8 สองท่อนซ้ายขวา มีจุดทึบที่ (3,1) ลูกศรทึบจากจุดนั้นชี้ตามทิศ (6,−2) กำกับว่า ∇f และเส้นตรงประที่สัมผัสเส้นโค้งที่จุดเดียวกันโดยตั้งฉากกับลูกศร ช่องขวาวาดเส้นตรงสองเส้น y=x และ y=−x ตัดกันที่จุดกำเนิด กำกับว่า level set ระดับ 0 มีวงกลมกลวงที่จุดกำเนิดพร้อมข้อความ "∇f = (0,0) ไม่มีทิศชันที่สุด และไม่มีเส้นสัมผัสเส้นเดียว" ขาวดำ เส้นน้อย]

**การจำแนกว่าจุดที่ $\nabla f = (0,0)$ เป็นจุดต่ำสุด จุดสูงสุด หรือจุดอานม้า เป็นเนื้อหาของสัปดาห์ 5** ซึ่งจะใช้ตัวเลขสี่ตัวที่เราหาเป็นแล้วในหัวข้อ 2 มาประกอบเป็น $D = f_{xx}f_{yy} - (f_{xy})^2$ สัปดาห์นี้เราหยุดที่การรู้ว่า **มีจุดแบบนี้อยู่ และมันไม่ใช่จุดต่ำสุดโดยอัตโนมัติ**

**ตอบ:** $\nabla f(3,1) = (6,-2)$ ตั้งฉากกับ level curve $x^2-y^2=8$ · $\nabla f(0,0) = (0,0)$ ซึ่งทำให้ทั้งทิศชันที่สุดและการตั้งฉากพูดไม่ได้ · จุดกำเนิดเป็นจุดอานม้า ไม่ใช่จุดต่ำสุด

## 3.5 อ่านเกรเดียนต์บนแผนที่ loss

กลับไปที่ $L(w,b)$ ของเรา เราคำนวณไว้แล้วในหัวข้อ 2.9 ว่า

$$
\nabla L(1,1) = (-6, -2) \qquad\text{และ}\qquad \nabla L(2,0) = (10, 4)
$$

อ่านสองผลนี้ทางเรขาคณิตบนแผนที่ contour ของ $L$

ที่จุด $(w,b) = (1,1)$ เกรเดียนต์ชี้ไปทาง $(-6,-2)$ คือไปทางซ้ายล่าง แปลว่าถ้าลด $w$ และลด $b$ ค่า $L$ จะ **เพิ่ม** เร็วที่สุด สิ่งที่เราอยากได้คือลด $L$ ฉะนั้นทิศที่เราสนใจคือทิศตรงข้าม

$$
-\nabla L(1,1) = (6, 2)
$$

คือไปทางขวาบน แปลว่าจากจุด $(1,1)$ การเพิ่ม $w$ พร้อมกับเพิ่ม $b$ จะลด $L$ ได้เร็วที่สุด และเพิ่ม $w$ ควรเพิ่มมากกว่า $b$ ในอัตราสามต่อหนึ่ง

ที่จุด $(2,0)$ เกรเดียนต์คือ $(10,4)$ ชี้ไปทางขวาบน ฉะนั้น $-\nabla L(2,0) = (-10,-4)$ ชี้ไปทางซ้ายล่าง จากจุดนั้นเราควรลดทั้ง $w$ และ $b$

สังเกตว่าจุดสองจุดนี้ให้ทิศ **ตรงข้ามกัน** แปลว่าจุดที่ดีที่สุดอยู่ **ระหว่าง** สองจุดนี้ — จุดหนึ่งบอกให้เดินขวา อีกจุดบอกให้เดินซ้าย ทั้งสองเสียงจึงชี้ไปที่บริเวณตรงกลาง นี่เป็นการอ่านเชิงคุณภาพที่ทำได้ทันทีจากเกรเดียนต์สองค่า โดยยังไม่ต้องแก้สมการอะไรเลย

และคำถามที่ค้างอยู่คือ **ถ้าเราเดินตาม $-\nabla L$ ทีละก้าวเล็ก ๆ ไปเรื่อย ๆ จะไปถึงจุดที่ดีที่สุดไหม และถ้าถึง ต้องกี่ก้าว** คำถามนี้ **สัปดาห์ 5 จะตอบในช่วงท้าย** และคอร์ส 15 สัปดาห์ภาคหน้าจะตอบให้ละเอียด สัปดาห์นี้เรามีแค่เข็มทิศ ยังไม่มีแผนการเดิน

## 3.7 ใช้ทำอะไรใน DS/CS

เกรเดียนต์คือ **เข็มทิศของทุกอัลกอริทึมที่ปรับพารามิเตอร์** ตรรกะทั้งหมดสั้นมาก คุณอยู่ที่จุดหนึ่งบนแผนที่ loss คุณอยากไปที่ต่ำกว่านี้ คุณคำนวณ $\nabla L$ ที่จุดที่ยืนอยู่ แล้วเดินไปทาง $-\nabla L$ นั่นคือทั้งหมด และเหตุผลที่มันใช้งานได้คือความหมายเชิงเรขาคณิตข้อที่ 1 ล้วน ๆ

ความยาว $\|\nabla L\|$ มีบทบาทในทางปฏิบัติที่ตรงไปตรงมาด้วย มันคือมาตรวัดว่า "ยังมีอะไรให้ปรับอยู่ไหม" ถ้า $\|\nabla L\|$ ยังใหญ่ แปลว่าอยู่บนที่ชัน ยังปรับได้อีกมาก ถ้ามันเล็กลงเรื่อย ๆ แปลว่ากำลังเข้าใกล้ที่ราบ นี่คือเหตุผลที่รายงานผลการเทรนโมเดลมักมีบรรทัดที่แสดงขนาดของเกรเดียนต์ควบคู่กับค่า loss เสมอ

ความหมายเชิงเรขาคณิตข้อที่ 2 คือการตั้งฉากกับ level curve มีประโยชน์ในการอธิบายพฤติกรรมที่คนพบแล้วงงบ่อย ๆ ถ้า contour เป็นวงรีแบนยาวเหมือนหุบเขาแคบ เกรเดียนต์ที่จุดบนผนังหุบเขาจะตั้งฉากกับ contour ซึ่งหมายความว่ามันชี้ **ข้าม** หุบเขา ไม่ใช่ชี้ **ตาม** หุบเขาไปทางจุดต่ำสุด ผลคือถ้าเดินตาม $-\nabla L$ อย่างซื่อ ๆ เส้นทางจะเป็นซิกแซกกระเด้งไปมาระหว่างสองผนัง แทนที่จะไถลลงตามแนวหุบเขา ปรากฏการณ์นี้อ่านออกได้จากเรขาคณิตของ contour ก่อนจะรู้สูตรอะไรเลย และการรู้ว่ามันเกิดจากอะไรทำให้เข้าใจว่าทำไมการปรับสเกลข้อมูลจึงช่วย — ปรับสเกลทำให้หุบเขาแคบกลายเป็นชามกลม และในชามกลม เกรเดียนต์ที่ตั้งฉากกับวงกลมก็ชี้ตรงเข้าหาศูนย์กลางพอดี

# 4. กฎลูกโซ่หลายตัวแปร

*(ตรงกับแถวที่ 4 ในตาราง 180 นาที — Lecture 30 นาที)*

## 4.1 หลักการ — ปิดวงกฎลูกโซ่จากสัปดาห์ 3

สัปดาห์ 3 เราฝึกกฎลูกโซ่หนักที่สุดในคอร์ส และสิ่งที่เราฝึกมีหน้าตาแบบนี้ ถ้า $z$ ขึ้นกับ $u$ และ $u$ ขึ้นกับ $t$

$$
\frac{dz}{dt} \;=\; \frac{dz}{du} \cdot \frac{du}{dt}
\qquad\qquad
t \;\longrightarrow\; u \;\longrightarrow\; z
$$

โครงสร้างคือ **โซ่เส้นเดียว** ค่าที่เปลี่ยนไหลจาก $t$ ไป $u$ ไป $z$ ทางเดียว ตอนนั้นเราตั้งค้างไว้ว่าถ้าโซ่แตกกิ่ง จะทำอย่างไร สัปดาห์นี้เราตอบ

สถานการณ์ใหม่คือ $z = f(x,y)$ ขึ้นกับสองตัวแปร และทั้ง $x$ และ $y$ ขึ้นกับ $t$ ตัวเดียวกัน เช่น $t$ คือเวลา และเรากำลังเดินไปตามเส้นทางในระนาบ ผลของการที่ $t$ เปลี่ยนจึงไหลไปถึง $z$ ผ่าน **สองทาง** พร้อมกัน

$$
t \;\longrightarrow\; x \;\longrightarrow\; z
\qquad\qquad
t \;\longrightarrow\; y \;\longrightarrow\; z
$$

**กฎลูกโซ่หลายตัวแปร** อัตราการเปลี่ยนรวมคือผลรวมของสิ่งที่ไหลมาแต่ละทาง

$$
\frac{dz}{dt} \;=\; \frac{\partial f}{\partial x}\cdot\frac{dx}{dt} \;+\; \frac{\partial f}{\partial y}\cdot\frac{dy}{dt}
\;=\; f_x \frac{dx}{dt} + f_y \frac{dy}{dt}
$$

ค่านี้เรียกว่า **total derivative** เพราะรวมผลกระทบทุกทางเข้าด้วยกัน

**สองข้อสังเกตที่ต้องเข้าใจ ไม่ใช่แค่จำ**

ข้อแรก **ทำไมเป็น "บวก" ไม่ใช่ "คูณ"** เพราะสองทางเป็นช่องทางที่ทำงาน **ขนานกัน** ไม่ใช่ต่อเนื่องกัน การคูณใช้เมื่อผลไหลผ่านสองขั้นเรียงกัน (เช่น $\frac{dz}{du}\cdot\frac{du}{dt}$ ที่ต้องผ่าน $u$ ก่อนถึงจะถึง $z$) การบวกใช้เมื่อผลมาถึงปลายทางจากหลายเส้นทางแยกกัน เทียบง่าย ๆ ว่า ถ้ามีท่อน้ำสองท่อเติมถังเดียวกัน อัตราการเพิ่มของน้ำในถังคือผลบวกของอัตราสองท่อ ไม่ใช่ผลคูณ

ข้อสอง **สังเกตว่าเครื่องหมายอนุพันธ์ต่างกันสองแบบในสูตรเดียว** $\dfrac{\partial f}{\partial x}$ ใช้ $\partial$ เพราะ $f$ มีสองตัวแปร ต้องตรึงอีกตัว ส่วน $\dfrac{dx}{dt}$ ใช้ $d$ เพราะ $x$ เป็นฟังก์ชันของ $t$ ตัวเดียว ไม่มีอะไรให้ตรึง และ $\dfrac{dz}{dt}$ ก็ใช้ $d$ เพราะเมื่อรวมทุกอย่างแล้ว $z$ กลายเป็นฟังก์ชันของ $t$ ตัวเดียว การใช้สัญลักษณ์ให้ถูกไม่ใช่พิธีการ มันคือการบอกว่าอะไรถูกตรึงและอะไรไม่ถูกตรึง

**รูปแบบเวกเตอร์** ถ้าเขียนด้วยเกรเดียนต์ สูตรจะกระชับขึ้นและเชื่อมกับหัวข้อ 3 ทันที

$$
\frac{dz}{dt} \;=\; \nabla f \cdot \left(\frac{dx}{dt},\; \frac{dy}{dt}\right)
$$

คือ **ผลคูณเชิงจุดของเกรเดียนต์กับเวกเตอร์ความเร็วของเส้นทาง** รูปนี้จะให้ผลลัพธ์ที่สวยมากในตัวอย่างที่ 3

**กรณีซ้อนสามชั้น** ถ้ามีตัวแปรกลางอีกชั้น เช่น $z = g(u)$ และ $u = h(x,y)$ และ $x, y$ ขึ้นกับ $t$ ให้ทำจากในออกนอกทีละชั้น

$$
\frac{du}{dt} = u_x \frac{dx}{dt} + u_y \frac{dy}{dt}
\qquad\text{แล้ว}\qquad
\frac{dz}{dt} = \frac{dz}{du}\cdot\frac{du}{dt}
$$

ชั้นในใช้กฎหลายตัวแปร ชั้นนอกใช้กฎเส้นเดียวของสัปดาห์ 3 **ผสมกันได้และควรผสม** เพราะการแยกเป็นชั้น ๆ ทำให้ตรวจงานง่ายกว่าการรวบทุกอย่างเป็นบรรทัดเดียว

[FIGURE | C | w04_f06_chain_tree_three_layers | แผนภาพต้นไม้แนวตั้งสี่ชั้นแบบเรียบขาวดำ ชั้นล่างสุดมีกล่องเดียวชื่อ t ชั้นถัดขึ้นมามีสองกล่องชื่อ x และ y โดยมีลูกศรจาก t ไปยังทั้งสองกล่องกำกับกิ่งว่า dx/dt และ dy/dt ชั้นถัดขึ้นมามีกล่องเดียวชื่อ u โดยมีลูกศรจาก x และ y เข้าหา u กำกับกิ่งว่า ∂u/∂x และ ∂u/∂y ชั้นบนสุดมีกล่องชื่อ z พร้อมลูกศรจาก u ขึ้นไป กำกับว่า dz/du ด้านขวาของภาพเขียนกฎการอ่านสองบรรทัดคือ "เดินตามกิ่งเดียวกัน = คูณ" และ "รวมทุกเส้นทางที่ถึงปลายทาง = บวก"]

## 4.2 ตัวอย่างที่ 1 — สองทางไหลรวมกัน *(ตรงไปตรงมา)*

**โจทย์:** ให้ $z = x^2 y$ โดย $x = t + 1$ และ $y = t^2$ จงหา $\dfrac{dz}{dt}$ ที่ $t = 1$

หาชิ้นส่วนทั้งสี่ชิ้นแยกกันก่อน แล้วค่อยประกอบ

$$
\begin{aligned}
\frac{\partial z}{\partial x} &= \frac{\partial}{\partial x}\big(x^2 y\big) = 2xy && \text{ตรึง } y \\
\frac{\partial z}{\partial y} &= \frac{\partial}{\partial y}\big(x^2 y\big) = x^2 && \text{ตรึง } x \\
\frac{dx}{dt} &= \frac{d}{dt}(t+1) = 1 && \\
\frac{dy}{dt} &= \frac{d}{dt}\big(t^2\big) = 2t &&
\end{aligned}
$$

หาค่าของ $x$ และ $y$ ที่ $t = 1$ ก่อนแทน เพราะอนุพันธ์ย่อยเขียนด้วย $x, y$ ไม่ใช่ $t$

$$
\begin{aligned}
x &= 1 + 1 = 2 && \\
y &= 1^2 = 1 && \\[4pt]
\frac{\partial z}{\partial x}\Big|_{t=1} &= 2(2)(1) = 4 && \text{แทน } x=2,\, y=1 \\
\frac{\partial z}{\partial y}\Big|_{t=1} &= 2^2 = 4 && \\
\frac{dx}{dt}\Big|_{t=1} &= 1 && \\
\frac{dy}{dt}\Big|_{t=1} &= 2(1) = 2 &&
\end{aligned}
$$

ประกอบตามสูตร

$$
\begin{aligned}
\frac{dz}{dt}\Big|_{t=1} &= \frac{\partial z}{\partial x}\cdot\frac{dx}{dt} + \frac{\partial z}{\partial y}\cdot\frac{dy}{dt} \\
&= (4)(1) + (4)(2) \\
&= 4 + 8 = 12
\end{aligned}
$$

**ตรวจคำตอบ — แทนค่าย้อนกลับแล้วทำเป็นหนึ่งตัวแปร** เขียน $z$ เป็นฟังก์ชันของ $t$ ตรง ๆ แล้วหาอนุพันธ์แบบสัปดาห์ 3

$$
\begin{aligned}
z &= x^2 y = (t+1)^2 \cdot t^2 && \text{แทน } x, y \\
\frac{dz}{dt} &= 2(t+1) \cdot t^2 + (t+1)^2 \cdot 2t && \text{product rule + กฎลูกโซ่} \\
&= 2t(t+1)\big[t + (t+1)\big] && \text{ดึง } 2t(t+1) \text{ ออกมา} \\
&= 2t(t+1)(2t+1) && \\
\frac{dz}{dt}\Big|_{t=1} &= 2(1)(2)(3) = 12 && ✓
\end{aligned}
$$

ตรงกัน ✓

**ตอบ:** $\dfrac{dz}{dt}\Big|_{t=1} = 12$

**ข้อสังเกต:** วิธีตรวจคำตอบข้างบนคือ "แทนค่าย้อนกลับให้เหลือตัวแปรเดียว" ซึ่งใช้ได้ทุกครั้งในโจทย์ระดับนี้ **ใช้ตรวจเสมอ** แต่ในงานจริงมันมักใช้ไม่ได้ เพราะฟังก์ชันไม่ได้ให้มาเป็นสูตรที่แทนย้อนได้ กฎลูกโซ่หลายตัวแปรจึงเป็นวิธีหลัก และการแทนย้อนกลับเป็นเพียงเครื่องตรวจในห้องเรียน

## 4.3 ตัวอย่างที่ 2 — ซ้อนสามชั้น *(มีชั้นเชิงเพิ่ม)*

ตัวอย่างนี้มีตัวแปรกลางเพิ่มมาอีกชั้น จึงต้องใช้กฎสองแบบผสมกัน คือกฎเส้นเดียวของสัปดาห์ 3 ที่ชั้นนอก และกฎหลายตัวแปรที่ชั้นใน

**โจทย์:** ให้ $z = u^3$ โดย $u = x + 2y$ และ $x = t^2$, $y = t$ จงหา $\dfrac{dz}{dt}$ ที่ $t = 1$

หาค่าทุกตัวที่ $t = 1$ ก่อน เพื่อกันความสับสน

$$
\begin{aligned}
x &= 1^2 = 1 && \\
y &= 1 && \\
u &= x + 2y = 1 + 2(1) = 3 &&
\end{aligned}
$$

**ชั้นใน** หา $\dfrac{du}{dt}$ ด้วยกฎหลายตัวแปร

$$
\begin{aligned}
\frac{\partial u}{\partial x} &= \frac{\partial}{\partial x}(x+2y) = 1 && \text{ตรึง } y \\
\frac{\partial u}{\partial y} &= \frac{\partial}{\partial y}(x+2y) = 2 && \text{ตรึง } x \\
\frac{dx}{dt} &= 2t = 2 && \text{ที่ } t=1 \\
\frac{dy}{dt} &= 1 && \\[4pt]
\frac{du}{dt} &= (1)(2) + (2)(1) = 2 + 2 = 4 && \text{กฎหลายตัวแปร}
\end{aligned}
$$

**ชั้นนอก** หา $\dfrac{dz}{du}$ ด้วยกฎธรรมดา แล้วคูณ

$$
\begin{aligned}
\frac{dz}{du} &= \frac{d}{du}\big(u^3\big) = 3u^2 = 3(3)^2 = 27 && \text{ที่ } u = 3 \\[4pt]
\frac{dz}{dt} &= \frac{dz}{du}\cdot\frac{du}{dt} = 27 \times 4 = 108 && \text{กฎเส้นเดียว (สัปดาห์ 3)}
\end{aligned}
$$

**ตรวจคำตอบ — แทนค่าย้อนกลับ**

$$
\begin{aligned}
u &= x + 2y = t^2 + 2t && \\
z &= u^3 = \big(t^2 + 2t\big)^3 && \\
\frac{dz}{dt} &= 3\big(t^2+2t\big)^2 \cdot (2t + 2) && \text{กฎลูกโซ่} \\
\frac{dz}{dt}\Big|_{t=1} &= 3\big(1 + 2\big)^2 \cdot (2+2) = 3(9)(4) = 108 && ✓
\end{aligned}
$$

ตรงกัน ✓

**ตอบ:** $\dfrac{dz}{dt}\Big|_{t=1} = 108$

**ข้อสังเกต:** ถ้าลองทำโดยไม่แยกชั้น เขียนเป็นบรรทัดเดียวจะได้ $\dfrac{dz}{dt} = 3u^2\big(u_x x'(t) + u_y y'(t)\big)$ ซึ่งถูกเหมือนกัน แต่โอกาสผิดสูงกว่ามาก เพราะต้องจำว่าตัวไหนอยู่ในวงเล็บและตัวไหนอยู่นอก **แยกชั้นแล้วเขียนค่าตัวเลขลงไปทีละชั้น ปลอดภัยกว่า**

## 4.4 ตัวอย่างที่ 3 — เดินไปแล้วค่าไม่เปลี่ยนเลย *(ผลลัพธ์ผิดคาด — มีแต่ใน note)*

**โจทย์:** ให้ $z = xy$ โดยเส้นทางคือ $x = t$ และ $y = \dfrac{6}{t}$ สำหรับ $t > 0$ จงหา $\dfrac{dz}{dt}$ ที่ $t = 2$

หาชิ้นส่วนทั้งสี่

$$
\begin{aligned}
\frac{\partial z}{\partial x} &= \frac{\partial}{\partial x}(xy) = y && \text{ตรึง } y \\
\frac{\partial z}{\partial y} &= \frac{\partial}{\partial y}(xy) = x && \text{ตรึง } x \\
\frac{dx}{dt} &= 1 && \\
\frac{dy}{dt} &= \frac{d}{dt}\big(6t^{-1}\big) = -6t^{-2} = -\frac{6}{t^2} &&
\end{aligned}
$$

หาค่าทุกตัวที่ $t = 2$

$$
\begin{aligned}
x &= 2 && \\
y &= \frac{6}{2} = 3 && \\
\frac{\partial z}{\partial x}\Big|_{t=2} &= y = 3 && \\
\frac{\partial z}{\partial y}\Big|_{t=2} &= x = 2 && \\
\frac{dx}{dt}\Big|_{t=2} &= 1 && \\
\frac{dy}{dt}\Big|_{t=2} &= -\frac{6}{4} = -\frac{3}{2} &&
\end{aligned}
$$

ประกอบ

$$
\begin{aligned}
\frac{dz}{dt}\Big|_{t=2} &= (3)(1) + (2)\left(-\frac{3}{2}\right) \\
&= 3 - 3 \\
&= 0
\end{aligned}
$$

**ตรวจคำตอบ — แทนค่าย้อนกลับ**

$$
z = xy = t \cdot \frac{6}{t} = 6 \qquad\Rightarrow\qquad \frac{dz}{dt} = \frac{d}{dt}(6) = 0 \quad ✓
$$

ค่า $z$ เป็น $6$ คงที่ตลอดเส้นทาง ทุก $t > 0$ ไม่ใช่แค่ที่ $t=2$ ✓

**สิ่งที่เกิดขึ้น:** ผลลัพธ์เป็นศูนย์ ทั้งที่ **ไม่มีชิ้นส่วนใดเป็นศูนย์เลย** — $\partial z/\partial x = 3 \ne 0$ · $\partial z/\partial y = 2 \ne 0$ · $dx/dt = 1 \ne 0$ · $dy/dt = -3/2 \ne 0$ ทั้งสี่ตัวไม่เป็นศูนย์ แต่สองผลคูณหักกันพอดี

เหตุผลอ่านได้จากเรขาคณิตของหัวข้อ 3 อย่างสวยงาม เส้นทางที่เราเดินคือ $xy = 6$ ซึ่งเป็น **level curve ของ $f(x,y) = xy$ ที่ระดับ 6** พอดี (นี่คือเส้นเดียวกับที่เราวาดไว้ในตัวอย่าง 1.4) เดินไปตาม level curve คือเดินไปโดยค่าไม่เปลี่ยน ดังนั้น $dz/dt$ ต้องเป็นศูนย์โดยไม่ต้องคำนวณอะไรเลย

เขียนด้วยรูปเวกเตอร์จะยิ่งชัด

$$
\begin{aligned}
\nabla f(2,3) &= (y, x)\big|_{(2,3)} = (3, 2) && \text{เกรเดียนต์} \\
\left(\frac{dx}{dt}, \frac{dy}{dt}\right)\Big|_{t=2} &= \left(1, -\frac{3}{2}\right) && \text{ความเร็วของเส้นทาง} \\[4pt]
\frac{dz}{dt} &= (3)(1) + (2)\left(-\frac{3}{2}\right) = 0 && \text{ผลคูณเชิงจุดเป็นศูนย์}
\end{aligned}
$$

ผลคูณเชิงจุดเป็นศูนย์แปลว่าเวกเตอร์สองตัว **ตั้งฉากกัน** และนั่นคือความหมายเชิงเรขาคณิตข้อที่ 2 ของหัวข้อ 3 ที่กลับมาปรากฏในรูปตัวเลข เกรเดียนต์ตั้งฉากกับ level curve และเวกเตอร์ความเร็วชี้ไปตามแนว level curve เพราะเส้นทางเราคือ level curve นั่นเอง สองตัวจึงตั้งฉากกัน และผลคูณเชิงจุดจึงเป็นศูนย์

**บทเรียนที่เอาไปใช้ได้:** $\dfrac{dz}{dt} = 0$ ไม่ได้แปลว่า "ไม่มีอะไรเกิดขึ้น" มันแปลว่า **การเปลี่ยนแปลงที่เกิดขึ้นสองทางหักกันพอดี** ในบริบทของโมเดล ถ้าปรับพารามิเตอร์สองตัวไปพร้อมกันในสัดส่วนที่พอดี ค่า loss อาจไม่ขยับเลยทั้งที่พารามิเตอร์เปลี่ยนไปมาก บริเวณแบบนั้นบนแผนที่ loss คือส่วนหนึ่งของ level curve และการเดินอยู่บนมันคือการเสียเวลาเปล่า การอ่านให้ออกว่ากำลังเดินตาม contour หรือกำลังเดินข้าม contour คือทักษะที่ตัวอย่างนี้สอน

**ตอบ:** $\dfrac{dz}{dt}\Big|_{t=2} = 0$ และเป็นศูนย์ทุกค่า $t>0$ เพราะเส้นทางอยู่บน level curve ของ $f$ ทั้งเส้น

## 4.5 กรณีที่พลาดบ่อย

| ที่พลาด | ทำไมพลาด | วิธีกัน |
|---|---|---|
| เขียน $\dfrac{dz}{dt} = \dfrac{\partial z}{\partial x}\cdot\dfrac{\partial z}{\partial y}\cdot\dfrac{dx}{dt}\cdot\dfrac{dy}{dt}$ | จำว่ากฎลูกโซ่คือการคูณ แล้วคูณทุกอย่างเข้าด้วยกัน | **คูณตามกิ่งเดียวกัน บวกข้ามเส้นทาง** ท่อสองท่อเติมถังเดียวกันให้บวกอัตรา ไม่ใช่คูณ |
| แทน $t$ ลงในสูตร $f_x$ โดยตรง | ลืมว่า $f_x$ เขียนด้วย $x$ กับ $y$ ไม่ใช่ $t$ | **หาค่า $x$ และ $y$ ที่ $t$ นั้นก่อน แล้วค่อยแทนใน $f_x$, $f_y$** เขียนสองบรรทัดนี้แยกออกมาให้เห็น |
| ใช้ $d$ กับ $\partial$ สลับกัน | คิดว่าเป็นเรื่องสัญลักษณ์ ไม่ใช่เรื่องความหมาย | $\partial$ ใช้เมื่อมีตัวแปรอื่นให้ตรึง · $d$ ใช้เมื่อไม่มี · เช็คว่าฟังก์ชันที่กำลังหาอนุพันธ์มีกี่ตัวแปร |
| ลืมกิ่งใดกิ่งหนึ่งในโจทย์สามชั้น | รวบทุกอย่างเป็นบรรทัดเดียว | **วาดแผนภาพต้นไม้ก่อน** แล้วนับว่ามีเส้นทางจาก $t$ ถึง $z$ กี่เส้น ต้องมีพจน์เท่านั้นพจน์ |
| ได้ $\dfrac{dz}{dt} = 0$ แล้วคิดว่าคำนวณผิด | ไม่คุ้นกับผลลัพธ์ศูนย์ | ศูนย์เป็นคำตอบที่ถูกได้ ดูตัวอย่าง 4.4 · ตรวจด้วยการแทนย้อนกลับ ถ้าได้ศูนย์เหมือนกันก็คือถูก |
| ไม่ตรวจคำตอบเพราะคิดว่าตรวจไม่ได้ | ไม่รู้ว่ามีวิธีตรวจ | ในโจทย์ระดับนี้ **แทน $x(t)$ และ $y(t)$ ย้อนกลับให้เหลือ $t$ ตัวเดียว แล้วหาอนุพันธ์แบบสัปดาห์ 3** ใช้ได้เกือบทุกข้อ |

## 4.6 ใช้ทำอะไรใน DS/CS

กฎลูกโซ่หลายตัวแปรตอบคำถามที่เกิดขึ้นทุกครั้งที่ปริมาณหนึ่งมีผลกระทบหลายทาง สมมติค่าที่วัดได้ตัวหนึ่ง เช่นขนาดของข้อมูลที่ใช้เทรน มีผลทั้งต่อความแม่นของโมเดลและต่อเวลาที่ใช้ และเรามีตัวชี้วัดรวมที่ขึ้นกับทั้งสองอย่าง การถามว่า "ถ้าเพิ่มขนาดข้อมูลอีกหน่อย ตัวชี้วัดรวมจะเปลี่ยนไปเท่าไร" เป็นคำถามที่ตอบด้วยสูตรนี้ตรง ๆ และคำตอบต้องเป็นผลบวกของสองช่องทาง ไม่ใช่ช่องทางเดียว การมองข้ามช่องทางใดช่องทางหนึ่งคือความผิดพลาดในการวิเคราะห์ที่พบบ่อยที่สุด

โครงสร้าง "ตัวแปรกลาง" ที่เราฝึกในตัวอย่าง 4.3 เป็นโครงสร้างเดียวกับที่เกิดขึ้นเมื่อโมเดลถูกสร้างเป็นชั้น ๆ คือ ข้อมูลเข้าถูกแปลงเป็นค่ากลาง ค่ากลางถูกแปลงเป็นค่ากลางอีกชั้น และชั้นสุดท้ายให้ค่า loss ออกมา การหาว่า loss ไวต่อพารามิเตอร์ในชั้นลึก ๆ แค่ไหน คือการเดินกฎลูกโซ่ย้อนจากปลายกลับมาต้นทางทีละชั้น เรื่องนี้เป็นหัวใจของคอร์ส 15 สัปดาห์ภาคหน้า ซึ่งจะสอนทั้งกลไกและวิธีจัดระเบียบการคำนวณให้ไม่ทำงานซ้ำ **สัปดาห์นี้เราสร้างของที่คอร์สนั้นจะใช้เป็นวัตถุดิบ นั่นคือกฎลูกโซ่ที่แม่นและนิสัยแยกชั้นก่อนคำนวณ**

สุดท้าย รูปเวกเตอร์ $\dfrac{dz}{dt} = \nabla f \cdot \left(\dfrac{dx}{dt}, \dfrac{dy}{dt}\right)$ เป็นสูตรที่จะปรากฏซ้ำในทุกวิชาที่เกี่ยวกับการหาค่าเหมาะที่สุด เพราะมันบอกว่า **ผลของการเดินไปทางหนึ่งขึ้นกับสองอย่างเท่านั้น คือเกรเดียนต์ที่จุดนั้น และทิศที่เลือกเดิน** และเมื่อสองอย่างนี้ตั้งฉากกัน การเดินนั้นไม่ให้อะไรเลย นี่เป็นข้อสรุปที่คุ้มค่าที่สุดของหัวข้อนี้

# สรุปสัปดาห์ 04 (1 หน้า)

| แนวคิด | สาระสำคัญ | ที่จะใช้ต่อ |
|---|---|---|
| **ฟังก์ชันสองตัวแปร** $f(x,y)$ | รับคู่อันดับคืนจำนวน · กราฟเป็นผิวในสามมิติ | ทุกหัวข้อที่เหลือ · $L(w,b)$ ในสัปดาห์ 5 |
| **level curve** $f(x,y)=c$ | เซตของจุดที่ค่าเท่ากัน · เส้นชิด = ชัน · เส้นห่าง = แบน · ต่างระดับตัดกันไม่ได้ · ระดับเดียวกันอาจขาดเป็นท่อนหรือตัดตัวเองได้ | อ่าน loss landscape · เข้าใจ feature scaling |
| **อนุพันธ์ย่อย** $f_x$, $f_y$ | ตรึงอีกตัวไว้แล้วหาอนุพันธ์ตามปกติ · $f_x(a,b)$ คือความชันของกราฟหน้าตัด | ทุกอย่างในสัปดาห์ 5 |
| **อนุพันธ์ย่อยอันดับสอง** สี่ตัว | $f_{xx}, f_{yy}, f_{xy}, f_{yx}$ · **$f_{xy}=f_{yx}$ เป็นข้อเท็จจริง** ใช้ตรวจงานตัวเอง · $f_{xy}$ วัดปฏิสัมพันธ์ | สัปดาห์ 5 — $D = f_{xx}f_{yy}-(f_{xy})^2$ จำแนกจุด |
| **$\nabla L(w,b)$** | $\dfrac{\partial L}{\partial w} = -2\sum x_i(y_i - wx_i - b)$ · $\dfrac{\partial L}{\partial b} = -2\sum(y_i - wx_i - b)$ | **สัปดาห์ 5 Capstone — ให้เท่ากับศูนย์แล้วแก้** |
| **เกรเดียนต์** $\nabla f = (f_x, f_y)$ | เป็น **เวกเตอร์** ในระนาบ · ชี้ทิศเพิ่มชันที่สุด · $-\nabla f$ ชี้ทิศลดชันที่สุด · **ตั้งฉากกับ level curve** · ความยาวคืออัตราการเพิ่มที่ชันที่สุด | สัปดาห์ 5 — $\nabla f = 0$ หาจุดวิกฤต และช่วง Bridge |
| **$\nabla f = (0,0)$** | ไม่มีทิศชันที่สุด · **ไม่ได้แปลว่าเป็นจุดต่ำสุด** อาจเป็นจุดอานม้า | สัปดาห์ 5 — second partial test |
| **กฎลูกโซ่หลายตัวแปร** | $\dfrac{dz}{dt} = f_x\dfrac{dx}{dt} + f_y\dfrac{dy}{dt} = \nabla f \cdot \left(\dfrac{dx}{dt},\dfrac{dy}{dt}\right)$ · **คูณตามกิ่ง บวกข้ามเส้นทาง** | คอร์ส 15 สัปดาห์ภาคหน้า |

**สามข้อที่ต้องจำให้ได้:**

1. **ตรึงก่อนหา** — ก่อนหาอนุพันธ์ย่อยทุกครั้ง เขียนออกมาว่าตรึงตัวไหนไว้ แล้วมองตัวนั้นเป็นเลขคงที่ ความผิดพลาดเกือบทั้งหมดของสัปดาห์นี้หายไปด้วยนิสัยเดียวนี้
2. **เกรเดียนต์เป็นเวกเตอร์ ไม่ใช่จำนวน** และมันมีความหมายเชิงเรขาคณิตสองข้อที่ต้องพูดได้ทั้งสองข้อ คือทิศเพิ่มชันที่สุด และตั้งฉากกับ level curve
3. **$\nabla L(w,b)$ หาได้แล้ว แต่ยังไม่ให้เท่ากับศูนย์** ก้าวถัดไปคือ Capstone ของสัปดาห์ 5 และเป็นก้าวที่ทั้งคอร์สนี้เดินมาเพื่อมัน
