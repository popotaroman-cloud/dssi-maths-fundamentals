# หนังสือ/แหล่งเรียนฟรีออนไลน์: Maths for Data Science (เรื่อง Derivative)

สรุปแหล่งเรียนฟรีที่แนะนำสำหรับการเรียนรู้เรื่อง **derivative/calculus** ที่เกี่ยวข้องกับ data science และ machine learning

---

## 1. Calculus Volume 1 (OpenStax)
- **ลิงก์:** https://openstax.org/details/books/calculus-volume-1
- **เหมาะสำหรับ:** ปูพื้นฐาน derivative ตั้งแต่นิยาม กฎการหา derivative ไปจนถึงการประยุกต์ใช้
- **จุดเด่น:** ตำราแคลคูลัสฟรีเต็มเล่ม เนื้อหาละเอียด เหมาะเป็นจุดเริ่มต้นถ้ายังไม่มีพื้นฐานแคลคูลัสมาก่อน

## 2. Mathematics for Machine Learning
- **ลิงก์ (PDF):** https://mml-book.github.io/book/mml-book.pdf
- **ผู้เขียน:** Deisenroth, Faisal, Ong
- **บทที่เกี่ยวข้อง:** Chapter 5 — Vector Calculus
- **จุดเด่น:** อธิบาย derivative, gradient, chain rule แบบเชื่อมโยงกับ ML โดยตรง เหมาะสำหรับคนมีพื้นฐานแคลคูลัสมาบ้างแล้ว

## 3. The Matrix Calculus You Need For Deep Learning
- **ลิงก์:** https://explained.ai/matrix-calculus/index.html
- **ผู้เขียน:** Terence Parr และ Jeremy Howard
- **จุดเด่น:** เจาะลึกเรื่องการหา derivative ของ matrix/vector (matrix calculus) ซึ่งตำราแคลคูลัสทั่วไปมักไม่ค่อยพูดถึง แต่จำเป็นมากสำหรับ deep learning

## 4. Deep Learning Book (Goodfellow, Bengio, Courville)
- **ลิงก์:** https://www.deeplearningbook.org/
- **บทที่เกี่ยวข้อง:** Part I (บทที่ 2-4)
- **จุดเด่น:** ทบทวนคณิตศาสตร์พื้นฐานที่จำเป็นสำหรับ ML รวมถึง calculus และ optimization

---

## แนะนำลำดับการอ่าน

1. เริ่มที่ **Calculus Volume 1 (OpenStax)** เพื่อปูพื้นฐาน derivative ให้แน่น
2. ต่อด้วย **Mathematics for Machine Learning** บท Vector Calculus เพื่อเชื่อมโยงเข้ากับ data science/ML
3. ตามด้วย **The Matrix Calculus You Need For Deep Learning** เมื่อต้องเริ่มทำงานกับ matrix/vector derivative
4. อ่าน **Deep Learning Book** บทที่ 2-4 เพื่อทบทวนภาพรวมคณิตศาสตร์ที่ใช้จริงในงาน ML
