## เป้าหมายของสัปดาห์

**หาค่าสุดขีดได้ทั้งหนึ่งตัวแปรและสองตัวแปร และสร้างสูตร linear regression ขึ้นเองด้วยมือตั้งแต่ต้นจนจบ**

จบสัปดาห์นี้ผู้เรียนต้องทำสิ่งเหล่านี้ได้:

- หาจุดวิกฤตของ $f(x)$ แล้วจำแนกด้วย **first derivative test** (ตารางเครื่องหมาย) และ **second derivative test**
- หาค่าสุดขีด**สัมบูรณ์**บนช่วงปิด โดยเทียบค่าที่จุดวิกฤตกับค่าที่ปลายช่วงทั้งสอง
- หาจุดวิกฤตของ $f(x,y)$ จาก $\nabla f = \mathbf{0}$ และรู้ว่าเมื่อ $f$ เป็นกำลังสอง ระบบนั้น **คือระบบสมการเชิงเส้น $2\times 2$** ที่แก้ได้ด้วยทักษะสัปดาห์ 2
- จำแนกจุดวิกฤตด้วย $D = f_{xx}f_{yy} - (f_{xy})^2$ เป็นต่ำสุด / สูงสุด / **อานม้า** / ทดสอบไม่ได้
- **สร้างสูตร $\hat w$ และ $\hat b$ ของ simple linear regression ขึ้นเองด้วยมือ** แล้วแทนข้อมูลจริงคำนวณจนได้ตัวเลข
- อธิบายได้ว่า gradient descent ทำอะไร และไล่รอบด้วยมือได้ 3 รอบ

**สิ่งที่ถือว่ารู้มาแล้ว:** ตารางเครื่องหมาย (สัปดาห์ 1) · ระบบสมการเชิงเส้นและการอ่านผลเฉลย (สัปดาห์ 2) · กฎการหาอนุพันธ์และความหมายของ $f'$, $f''$ (สัปดาห์ 3) · อนุพันธ์ย่อยและเกรเดียนต์ (สัปดาห์ 4)

| ตั้งค้างไว้ที่ | เรื่องที่ค้าง | ปิดที่ไหนในสัปดาห์นี้ |
|---|---|---|
| **สัปดาห์ 1** | **ตารางเครื่องหมาย** — เรียนไปแล้วแต่ยังไม่เห็นว่าใช้ทำอะไรจริงจัง | หัวข้อ 1 — **first derivative test** คือตารางเครื่องหมายของ $f'$ ตรง ๆ ไม่มีอะไรใหม่ |
| **สัปดาห์ 1** | โดเมนที่ต้องยกเว้น | หัวข้อ 1 — โจทย์ประยุกต์ที่โดเมนคือ $x > 0$ และจุดวิกฤตที่หลุดโดเมนต้องทิ้ง |
| **สัปดาห์ 2** | **ระบบ overdetermined — สมการมากกว่าตัวแปร ไม่มีผลเฉลยพอดี** | **หัวข้อ 3 (Capstone)** — ถ้าแก้เป๊ะไม่ได้ ก็หาค่าที่ผลรวมกำลังสองของส่วนเหลือน้อยสุด **นี่คือการปิดวงที่สำคัญที่สุดของคอร์ส** |
| **สัปดาห์ 2** | สามกรณีของระบบสมการ (คำตอบเดียว / ไม่มี / มีมากมาย) | หัวข้อ 2 ตัวอย่างที่ 3 และหัวข้อ 3 ตัวอย่างที่ 3 — กรณี $D = 0$ คือกรณี "ระบบมีผลเฉลยมากมาย" ปรากฏตัวในรูปของการหาค่าเหมาะที่สุด |
| **สัปดาห์ 3** | **จุดวิกฤต** — นิยามไว้แล้วแต่ยังไม่ได้ใช้ | หัวข้อ 1 — จำแนกจุดวิกฤตครบทั้งสองการทดสอบ |
| **สัปดาห์ 3** | ความหมายของ $f''$ และความเว้า | หัวข้อ 1 — second derivative test |
| **สัปดาห์ 4** | **อนุพันธ์ย่อยของ $L(w,b)$ — หาไว้แล้วแต่ยังไม่ได้ให้เท่ากับศูนย์** | **หัวข้อ 3 (Capstone)** — เอาอนุพันธ์ย่อยคู่นั้นมาให้เท่ากับศูนย์ แล้วแก้ระบบต่อจนได้สูตร |
| **สัปดาห์ 4** | เกรเดียนต์ชี้ทิศที่ฟังก์ชันเพิ่มชันที่สุด | หัวข้อ 4 — จึงเดินสวนทางเกรเดียนต์เพื่อลดค่า |

## หมายเหตุการสอน

1. **หัวข้อ 3 คือหัวใจของคาบและของคอร์ส** ถ้าเวลาไม่พอ ให้ตัดเวลาจากหัวข้อ 1 (ซึ่งเป็นการต่อยอดสัปดาห์ 3 โดยตรง) ห้ามตัด Capstone
2. **ห้ามข้ามขั้นใน Capstone** ลำดับ 7 ขั้นถูกออกแบบให้เห็นว่าสูตรที่ใช้กันทั่วโลกไม่ได้ลอยมาจากฟ้า แต่เป็นผลของ "อนุพันธ์เท่ากับศูนย์" ที่เรียนมาทั้งคอร์ส
3. **หัวข้อ 4 เป็นประตู ไม่ใช่บทเรียน** สอน 25 นาทีแล้วหยุด ห้ามลากไปถึง momentum หรือ learning-rate schedule — นั่นเป็นงานของคอร์ส 15 สัปดาห์
4. ฟังก์ชันสองตัวแปรทุกตัวในสัปดาห์นี้เป็น **กำลังสอง** โดยตั้งใจ เพราะทำให้ $\nabla f = \mathbf{0}$ กลายเป็นระบบเชิงเส้นที่แก้ด้วยมือได้ **ต้องชี้ให้นักศึกษาเห็นข้อนี้ชัด ๆ** ว่าเป็นการใช้ทักษะสัปดาห์ 2 ไม่ใช่เรื่องบังเอิญ

**เนื้อหาที่ตัดออกจากสัปดาห์นี้ (ห้ามเผลอสอน):** ความคอนเวกซ์ · ตัวคูณลากรานจ์ · ridge/regularization · normal equations กรณี $p$ ตัวแปร · Hessian (ใช้ $D$ ตรง ๆ โดยไม่เรียกชื่อ) · neural network
